### 2.2 Support matrix, setup, and packaging gates (T015)

**Branch**: `feat/v2.3.0-qwen-video2x-openworker` | **PR**: none | **Merged to**: n/a

**Plan specification**: Baseline from observed data. Label untested combinations not proven here. Installer and desktop detect a separately installed executable. Declarative parity. Do not download or bundle Video2X. Hub handoff is a known gap unless a released Hub version supplies evidence.

**What happened**: `VIDEO_ENHANCEMENT_SUPPORT` is the SSOT. Adapter, panel, Settings, installer, and baseline all consume those keys and strings. `NEXUS_VIDEO2X_PATH` wins over `video.video2xPath`. Empty setting clears the path; a non-empty path must be absolute for the sidecar platform. Installer Configuration and Complete pages show a note, not a toggle. Hub remains DF-2.

**Key files changed**: `core/video/video-enhancement-support.json`, `core/video/videoEnhancementSupport.ts`, `desktop/src/pages/settings/VideoSettings.tsx`, `desktop/sidecar/src/protocol.ts`, `desktop/sidecar/src/handlers.ts`, `scripts/installer/src/nexus_installer/video_enhancement_support.py`, `docs/v2/v2.3/benchmarks/video-enhancement-baseline.md`, `README.md`

**Troubleshooting**:
- **Problem**: Packaging tests first asserted the full JSON `setupCopy` / `installerNote` as a contiguous substring of the Python source. Ruff E501 forced implicit string concatenation, so the source is not one substring even though runtime equality holds. Exact error shape: assertion failed because the concatenated Python source is not a single contiguous copy of the JSON sentence.
- **Attempted**: Require the full JSON sentence in `.py` source.
- **Root cause**: Python adjacent-string concatenation is runtime-equal, not source-equal.
- **Resolution**: Tests assert runtime imports plus distinctive fragments (`never installed by this wizard`, `does not download, bundle, or search`) and the baseline tokens `` `video.video2xPath` `` and `fake-deterministic`.
- **Problem**: `userEvent.type` of a Windows `C:\...` path interpreted `\v` as a vertical tab.
- **Resolution**: Tests type a POSIX absolute path `/opt/video2x/video2x`.

**Verification**: Packaging 6 passed. Desktop Video Settings and path IPC tests pass. Installer pytest for support copy and ConfigurationPage pass. `core/registry/catalog.json` has no Qwen3.8 entry.
