## Video Lab Enhance surface

- Enhance appears only when a completion event carries a durable output id and SHA-256. Playable clips without identity, failed generations, and enhanced child messages do not offer Enhance.
- The panel offers the seven semantic selections from the Phase 1 contract (animation 2x/4x, general 4x, Smooth 2x, and the three combined modes). It shows derived resolution and rational fps and never exposes arbitrary 48/60 or target-resolution fields.
- React sends only typed enqueue fields. Backend flags, processor names, and model paths stay in the sidecar.
- Copy states that enhancement synthesizes pixels and frames, can introduce artifacts, uses local compute, and never replaces the original.
- Capability reasons disable presets with visible setup text. Recheck capability can move a host from ready to unavailable without losing the draft source.
- Progress uses known percent when the sidecar supplies it and otherwise an indeterminate bar plus stage text. Status is not color-only. Cancel targets one child id.
- The page keeps polling parent jobs after the panel closes, so a later success still appears as a separate assistant message. Downloads use `nexus-video-original-` and `nexus-video-enhanced-` names with distinct accessible names. Enhanced lightbox copy is labeled "Copy workflow and provenance".
- The shared generation queue bar labels `video_enhancement` children and exposes `Cancel enhancement <id>`. Sidecar generation cancel already delegates to the enhancement runtime.

## Troubleshooting and corrections

- Uncommitted draft UI already covered the panel and client. Remaining gaps were page-level completion recovery, distinct downloads, queue-bar labeling, preset mapping tests, capability recheck, live-region stability, and keyboard order.
- The first page test used `/separate synthesized file/i`, which matched both the live region and the transcript. Assertions now target the transcript dimensions.
- Copy-workflow controls live in the media lightbox, so the page test opens the enhanced clip before checking the provenance accessible name.
- `inMemoryVideoEnhancementCapability` originally accepted a `Partial` override that broke the capability discriminated union. The helper now returns only the ready fixture.
