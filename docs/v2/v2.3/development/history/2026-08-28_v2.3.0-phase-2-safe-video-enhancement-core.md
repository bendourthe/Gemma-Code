## Backend-neutral contract

- Requests support only `upscale`, `interpolate`, and `upscale_interpolate`, with animation 2x/4x, general 4x, and integer 2x interpolation presets.
- Validation snapshots own data properties once, rejects accessors, symbols, unknown fields, unsafe arithmetic, malformed identities, and incompatible mode fields, and returns deeply frozen request data.
- Capability, success, and failure values from a backend are independently normalized into exact, bounded, immutable schemas. Malformed terminal data becomes a safe `internal_error`; malformed, non-finite, or regressing progress becomes truthful indeterminate progress rather than failing the job.
- A successful core result is still `staged`, never published. It must match the request, child identity, immutable source facts, expected ordered stages, timeout-bounded timings, backend hash, actual selected platform and device, same-run processor/model/scalar arguments, and a distinct absolute MP4 staging path.
- Cancellation remains authoritative over a late backend success. Native `AbortSignal` state is read without trusting hostile own-property shadows, progress callbacks stop after terminal settlement, and progress-consumer failures cannot control the backend lifecycle.

## Guarded Video2X adapter

- Configuration precedence is `NEXUS_VIDEO2X_PATH` followed by typed setting `video.video2xPath`; the adapter never searches `PATH`, installs Video2X, downloads a model, or contacts a service.
- Compatibility requires exact Video2X 6.4.0 version output, pinned help grammar, AVX2 evidence, tagged Vulkan device data, deterministic lowest-ID discrete or integrated GPU selection, and per-preset model readiness.
- Preset mappings exactly match the Phase 1 contract. Combined mode runs upscale before interpolation in separate private stages with fresh empty working directories.
- Job-root leaves are deterministically derived from the first 32 lowercase hexadecimal characters of the SHA-256 digest of the persisted child-job ID. Collisions fail closed without reusing or deleting the pre-existing directory.
- Source and executable size, file identity, canonical path, and SHA-256 are revalidated around execution. Staged output must be a nonempty contained regular file that is neither a symlink nor a hard-link alias of the source.
- Process output and progress parsing are byte-bounded on valid UTF-8 codepoint boundaries. One run-local deadline bounds probes, hashing, process work, and injected operations even when an injected dependency ignores `AbortSignal`; model-readiness caching has explicit invalidation and a bounded TTL.
- Diagnostics redact workspace, home, staging, executable, source, and secret-like environment values before they can leave the adapter. A successful result carries same-run execution provenance instead of requiring Phase 3 to reconstruct a preset or run another capability probe.
- Failure and cancellation clean only an identity-verified exact job-owned path. When process-tree termination is unproven, cleanup, validation, and promotion are forbidden and the exact root remains quarantined. A successful run retains the final private staged MP4 for Phase 3 validation, provenance, atomic promotion, and indexing.

## Native process boundaries

Linux launches the exact executable directly with `shell: false` in a new process group. Nexus sets its terminal reason first, writes the optional graceful `q`, escalates to `SIGTERM` and `SIGKILL` for the negative process-group ID, checks for orphaned descendants after a normal leader exit, and settles after a bounded acknowledgement even when a pathological child never emits `close`. Non-`ESRCH` signal failures never fall back to killing only the leader, return `terminationConfirmed: false`, retain quarantine, and start only bounded best-effort background reaping.

Windows launches an absolute PowerShell executable with `-NoProfile`, `-NonInteractive`, and one fixed encoded loader program. A minimal loader environment authenticates the private control manifest and fixed C# source by out-of-band path and SHA-256 values; the source compiles in memory, so no generated mutable script or assembly exists. The helper validates and consumes the exact structured manifest, passes a sorted explicit Unicode child environment block, calls `CreateProcessW` with `CREATE_SUSPENDED`, constrains inherited standard handles with `STARTUPINFOEX`, assigns the process to a `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` job before resume, and uses an independent bounded watchdog. Node-side timeout and cancellation remain authoritative, cancellation wins races with timeout, and a missing `close` acknowledgement settles safely with a bounded diagnostic. Windows AVX2 evidence uses `IsProcessorFeaturePresent(40)` and treats false as unavailable rather than proof of unsupported hardware.

Inherited environments are scrubbed for secret-shaped names and values plus `APPDIR`, `GLIBC_TUNABLES`, and every `LD_*`, `DYLD_*`, `VK_*`, `COR_*`, `CORECLR_*`, `COMPlus_*`, and `DOTNET_*` injection surface. Post-settlement process listeners are detached and output streams are paused, preventing late output from re-entering completed invocations.
