## 6. Assumptions Made

- **ctypes GlobalMemoryStatusEx is available in a frozen windowed PyInstaller process**: that is the point of preferring it over PowerShell. If a specific freeze layout blocks `ctypes.windll`, the catalog will show "RAM not detected" rather than invent a number.
- **Integer GB floor matches host_detect**: Install Path display still shows one-decimal GB in the label; stored `free_disk_gb` is the floored integer.
