- **Auto-title**: persist through `chat.explorer.renameChat` (not `byUser`). Immediate `fallbackTitle` so the rail never stays `New chat` after a first send. Optional model refine after the first assistant turn completes. Never overwrite a user rename.

- **Generate honesty**: split CUDA-unavailable vs weights-missing vs true GPU-not-ready. Telemetry VRAM is not `torch.cuda.is_available()`. No stub PNG on a real host (`NEXUS_DIFFUSION_ALLOW_STUB` stays test-only).
