## Locked product decisions

- **Do not start** until v2.2.7 is complete on `develop`. Do not re-run v2.2.0-v2.2.7 as greenfield.
- **Long-running RPCs**: `chat.send`, coding send, image generate, and video generate must not share the 15s default timeout. Streaming methods stay open for the stream (or a documented minutes-class timeout). `sidecar response timeout` is only for a dead/hung sidecar, never for a slow first token. Do not raise every RPC to 10 minutes.
- **Installed means installed**: if Ollama `/api/tags` has `gemma4:12b` (or an alias of `gemma-4-12b-it-gguf`), Settings shows Downloaded/Ready, not Download. Snapshot-selected-but-missing stays Retry (v2.2.5 lock).
- **One Models contract**: installer Models tab and desktop Settings Models tab share sort, family collapse, `hideBelowVramGB`, compact row density, over-budget grayed-at-end, and downloaded highlight. If Settings shows a row, the installer shows that row (or both hide it for the same VRAM reason). Tab pickers (`QuickModelSwitcher`) use that same order.
- **Hub latest**: Active tag matches GitHub `/releases/latest`. `PromptInjectionScanner` stays on. Apply must not fail the whole bundle: clean skills apply, flagged skills quarantine, operator sees counts, Active still moves to latest.
- **Four history panes**: Chatbot, Agents, Images, Videos use the same FolderTree chrome (folders, rename, delete, new session, collapse). Collapsed state is an icon rail (new/folder plus per-session marks), not an empty 24px gutter. Delete confirm is a rounded quiet dialog, not a square flash-red OS button.
- **Rail**: small top margin under the title bar so Chatbot is not flush. Do not bring back the old brand block.
- **Orbs**: keep `AgentStateOrb` / `orbEngine`. Do not `npm install thinking-orbs`. Chat/Agents pending orbs are centered in the bubble at a size that reads as the reference playground, not a 20px left-aligned spinner. Image/Video pending stays hero. Reduced-motion: static ring.
- **Cold start Chatbot**. Peeking a tab never loads weights. Tab labels: Chatbot, Agents, Images, Videos. Tools always on.
- **Do not bump** package.json. **Do not disable** the scanner. **No live GPU in PR CI**.
