## 2. Chronological steps

### 2.1 User bubble before not-installed

**Plan specification**: Append and persist the user message before residency or not-installed returns. Empty prompts stay empty. After Phase 2 this branch is rare; it must still show Hi.

**What happened**: `ChatPage.handleSubmit` writes the trimmed user text first when residency is `not-installed` or `defer`, then writes the assistant explanation and returns. Confirm-to-switch still does not append (cancel must not leave a stray bubble). `CodingPage` mirrors this by recording a local turn with the user prompt and the same notice.

**Key files changed**: `desktop/src/modules/chat/ChatPage.tsx`, `desktop/src/modules/coding/CodingPage.tsx`

### 2.2 Agents chrome

**Plan specification**: Remove the pink h1. Stop passing harness / tool-calling badges from Chatbot and Agents.

**What happened**: Coding header is the compact switcher (right-aligned) plus the workspace path field. Session tabs Chat / Memory / Trace / Sessions remain. `ModelSelector` still accepts badge props so unit tests of that component stay valid; Coding and Chat no longer pass them.

**Key files changed**: `desktop/src/modules/coding/CodingPage.tsx`

### 2.3 Tools always on

**Plan specification**: Delete Enable tools. Keep ConfirmationGate and sandbox.

**What happened**: Chat no longer has `enableTools` state or the checkbox. `MessageList` is passed `enableTools={true}`. Shared tests still prove cards render when tools are on and hide when a host opts out.

**Key files changed**: `desktop/src/modules/chat/ChatPage.tsx`, `desktop/tests/ChatPage.test.tsx`
