## What was implemented

- **3.1 (T007)**: The Image/Video top `<header>` renders only when it has a visible child (render-when-children, wrapped in the none-installed condition), so installed hosts show no empty bar; the get-more-models CTA stays inside that header and remains reachable exactly when no models are installed. Default studio session titles changed from "New session" to "New chat" (`sessionTitleFromPrompt` fallback).
- **3.2 (T008)**: All 12 image/video catalog rows now carry `visualTokenBudget` in the pre-existing shape (schema and DTO path already accepted it end-to-end; only data was missing). Image rows: `maxImages: 1` plus honest per-row `maxPixels` (1024px rows 1048576; SANA 2K 4194304; SANA 4K 16777216). Video rows: Wan 2.1 81 frames / 5 s, Wan 2.2 121 frames / 5 s (published pipeline defaults); SANA Video and LongCat use the `core/chat/vision.ts` defaults. No `contextWindow` was set on any diffusion/video row. `composerSessionUsage` fills the studio Context bar via `denominatorKind: "visual"`. Last-output img2img / `continueFrom` untouched.
