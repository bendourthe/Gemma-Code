## 2. Chronological steps

### 2.1 Compact inline media + lightbox

**Plan specification**: max-height about 40vh, width auto, no minHeight slab, no 48rem default. Click opens a modal with fullscreen, download, and copy image.

**What happened**: `MessageBubble` uses a compact media style and opens `MediaLightbox` on click. Fullscreen, download, and copy image are in the dialog. Pages pass extra studio actions through `renderPreviewExtra`.

**Key files changed**: `desktop/src/shared/chat/MessageBubble.tsx`, `desktop/src/shared/chat/MessageList.tsx`

### 2.2 In-chat actions vs dialog actions

**Plan specification**: In-chat row is Download + Copy image only. Prompt/seed/remix live in the dialog.

**What happened**: Image Studio in-chat row is download + copy image. Copy workflow, RecallActions, and use-as-source render inside the lightbox. Video Lab in-chat row is download only (no still to copy); workflow actions are in the lightbox.

**Key files changed**: `desktop/src/modules/image/ImageStudioPage.tsx`, `desktop/src/modules/video/VideoLabPage.tsx`

### 2.3 Empty completes

**Plan specification**: Reject empty, whitespace, invalid base64, and 1x1 transparent PNG before patching media.

**What happened**: `isUsableImageBase64` / `isUsableVideoPath` gate complete events. Opaque test stubs such as `PNG==` still pass (img onError remains the decode backstop). 1x1 PNG IHDR is rejected.

**Key files changed**: `desktop/src/shared/studio/usablePayload.ts`
