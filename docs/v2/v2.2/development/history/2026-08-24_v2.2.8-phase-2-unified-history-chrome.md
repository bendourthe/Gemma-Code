## 2. Chronological Steps

### 2.1 One FolderTree on four tabs (T004, T005)

**Plan specification**: Agents get the same left pane as Chatbot (folders optional, named sessions, rename/delete). Image/Video panes match width, collapse, and empty chrome. Collapsed state is an icon rail like the module sidebar. Sidecar down: empty hint + banner, no fake rows. Delete while collapsed still confirms.

**What happened**: Extracted `CollapsibleHistoryAside` (280px / 56px) and wired it into ChatPage, StudioHistoryPane, and CodingPage. FolderTree gained a `collapsed` prop that keeps new/folder icons and per-session marks. Agents use `createCodingSessionsAsChatExplorer` over `coding.sessions.list` / rename / delete / start. Sessions without sidecar folders render as a flat list. Overlay folders live in `localStorage` (DF-33). Chatbot stays on `chat.explorer.*`.

**Key files changed**: `desktop/src/modules/chat/FolderTree.tsx`, `desktop/src/modules/chat/ChatPage.tsx`, `desktop/src/modules/coding/CodingPage.tsx`, `desktop/src/shared/explorer/StudioHistoryPane.tsx`, `desktop/src/shared/explorer/CollapsibleHistoryAside.tsx`, `desktop/src/shared/explorer/codingSessionsAsChatExplorer.ts`

**Troubleshooting**: Lucide `Folder` collided with the explorer `Folder` type; aliased to `FolderIcon`. CodingPage JSX duplication from a partial replace was truncated back to one return.

**Verification**: Desktop vitest 123/123 on the Phase 2 file set. Collapse test asserts 56px with new/folder visible. CodingPage rename/delete uses `tree-rename-*` / `confirm-delete-ok`.

### 2.2 Modern delete confirm (T006)

**Plan specification**: Rounded card, quiet Cancel, rounded destructive Delete using status tokens, not a square `#d33` fill. Esc/Cancel: no delete. Missing label still names the kind.

**What happened**: Restyled `folder-tree-confirm-delete`. Escape listener dismisses. `itemNoun` covers chat vs session. Collapsed rail hides inline trash; Delete key and context menu still open the same dialog.

**Key files changed**: `desktop/src/modules/chat/FolderTree.tsx`, `desktop/tests/FolderTree.test.tsx`

### 2.3 Testing and Stabilization

FolderTree, ChatPage, CodingPage, StudioHistoryPane, ImageStudioPage, adapter tests. CI comment on `test:shell`. Session history this file. No live GPU.

- Sessions tab on Agents is a pointer to the left pane rather than a second list.

## 6. Assumptions Made

- 56px matches the module sidebar compact rail and is wide enough for new/folder plus a 32px session mark.
- Persist collapse per pillar (`nexus.chat.chatsPaneCollapsed`, `nexus.coding.historyCollapsed`, `nexus.image.historyCollapsed`, `nexus.video.historyCollapsed`).
- Overlay folders are enough to satisfy "folders optional" without a sidecar schema this phase.
