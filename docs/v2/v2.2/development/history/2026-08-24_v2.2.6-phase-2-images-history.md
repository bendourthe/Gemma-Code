## 2. Chronological Steps

### 2.1 Persist image turns (2.1)

**Plan specification**: On send, append user turn first. On usable complete, persist media ref and lastOutputRef. On hydrate, rebuild MessageList. Sidecar down: do not claim saved.

**What happened**: ImageStudioPage auto-creates a named session on first send when sidecar is up / an explorer is injected. persistTurn no-ops when sidecar is down. Completes persist outputPath when it is a real path, never a data: blob. Errors persist text and do not move lastOutputRef.

### 2.2 Implicit last-image edit (2.2)

**Plan specification**: Empty attachments + usable lastOutputRef -> img2img. User attachments win. Unreadable lastOutputRef -> typed error, not silent txt2img.

**What happened**: inferImageIntent gained lastOutputRef. handleSubmit fail-closes with UNREADABLE_OUTPUT_TEXT when the probe rejects the path.

### 2.3 Tests (2.3)

Implicit img2img + persist, remount hydrate, missing-file hydrate. Existing txt2img test now allows the session title to repeat the prompt in the tree.
