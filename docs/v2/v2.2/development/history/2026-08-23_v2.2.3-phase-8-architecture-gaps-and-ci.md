The cross-installer prompt asked for real installers to run on their target operating systems. The parity declaration therefore records their desktop payload as not staged and keeps target acceptance open instead of claiming equivalent behavior.

## 6. Assumptions Made

- **Exact duplication defines the safe composer boundary**: shared style objects move; differing interaction markup stays local.
- **Develop needs early shell coverage at bounded cost**: Ubuntu catches TypeScript sidecar and Rust regressions; full OS packaging remains a main/manual responsibility.
- **N/A is not equivalent proof**: Windows taskbar and process-creation features are explicitly not applicable on Unix.
- **No structural churn is a valid audit result**: fully triaged intentional files and directories do not need to move merely to satisfy a cleanup phase.
