## 2. Chronological Steps

### 2.1 Row icons (T014)

**Plan specification**: Lucide pencil and trash on each chat row. Keep the context menu. Delete still confirms. Icons `stopPropagation` so they do not steal the open-chat click. Keyboard Delete/F2 stay.

**What happened**: Chat rows render Pencil and Trash2 after the title. Rename starts the existing inline input. Trash opens the existing confirm dialog. Folder rows stay icon-free (context menu and F2 still apply).

**Key files changed**: `desktop/src/modules/chat/FolderTree.tsx`, `desktop/tests/FolderTree.test.tsx`

### 2.2 Recklick rename (T015)

**Plan specification**: If selected kind is chat and the user left-clicks the same chat id, call the start-rename path. First click on an unselected chat still opens only.

**What happened**: `handleClick` compares `selected` to the clicked chat id. Match plus not already renaming starts rename and skips `onOpenChat`. Unselected click still selects and opens.

**Key files changed**: `desktop/src/modules/chat/FolderTree.tsx`

### 2.3 Chats pane pill (T016)

**Plan specification**: Reuse the v2.2.4 Sidebar collapse pill on the ChatPage chats aside. Collapsed transcript stays usable. Expand target at least 24px. Persist with a namespaced localStorage key. Do not collapse the main rail.

**What happened**: `CHATS_PANE_STORAGE_KEY` is `nexus.chat.chatsPaneCollapsed` (Sidebar stays `nexus.sidebar.compact`). Expanded width 280px. Collapsed width 24px with FolderTree unmounted. Pill reuses `.nexus-sidebar-collapse-pill` plus `.nexus-chats-collapse-pill` (24px min). Expand restores the tree.

**Key files changed**: `desktop/src/modules/chat/ChatPage.tsx`, `desktop/src/styles/globals.css`, `desktop/tests/ChatPage.test.tsx`
