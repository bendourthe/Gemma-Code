## 2. Chronological Steps

### 2.1 Captioned hero generation state

**Plan specification**: Use the existing hero orb for pending media, keep active motion cyan, expose useful captions, and avoid widening plain chat bubbles.

**What happened**: AgentStateOrb gained optional inline or hero captions without changing its size contract. Media-bearing pending bubbles use a centered transparent hero surface; text pending states keep the inline orb. Media width is scoped by content type, so ordinary chat bubbles retain their prior fit-content layout.

**Key files changed**: `desktop/src/components/agentState/AgentStateOrb.tsx`, `desktop/src/components/agentState/mapping.ts`, `desktop/src/shared/chat/MessageBubble.tsx`, `desktop/src/shared/chat/MessageList.tsx`

### 2.2 Terminal generation honesty

**Plan specification**: A completion without bytes must become a written error, queue failures must reach the renderer, and actions must exist only for displayable assets.

**What happened**: QueuePump exposes a typed error callback, the sidecar records error completions for queue exceptions and missing outputs, and Video completion is no longer double-gated on optional workflow metadata. Image Studio and Video Lab clear output, workflow, and media state on terminal or decode failure, preventing empty cache entries and false recall actions.

**Key files changed**: `core/generations/queuePump.ts`, `core/generations/index.ts`, `desktop/sidecar/src/handlers.ts`, `desktop/src/modules/image/ImageStudioPage.tsx`, `desktop/src/modules/video/VideoLabPage.tsx`

### 2.3 Playable Tauri video URLs

**Plan specification**: Convert generated filesystem paths for the webview and limit asset access to the outputs directory.

**What happened**: App supplies `convertFileSrc` to Video Lab. The Tauri dependency enables `protocol-asset`, the asset scope admits only the video output subtree, and the CSP admits the local asset schemes. Image and video elements expose visible error fallbacks.

**Key files changed**: `desktop/src/App.tsx`, `desktop/src-tauri/Cargo.toml`, `desktop/src-tauri/tauri.conf.json`

## 6. Assumptions Made

- **Optional workflow metadata must not block playable video**: MP4 display is the completion contract; metadata embedding remains best-effort.
- **Media element failure is terminal for display state**: A decoded or playable asset is required before recall actions can remain visible.
- **The narrow Tauri asset scope is sufficient**: Generated videos are written beneath `~/.nexus/outputs/videos/`; no broader filesystem grant is needed.
