# Development Log: v2.2.5 Phase 3 - Settings Models installer parity

**Date**: 2026-08-23
**Operator**: Project owner
**Objective**: Settings > Models scrolls, sorts, and badges like the installer. Origin, release date, and censored/uncensored chips are visible. Qwen 3.5 4B is Downloaded only when the Ollama tag (or alias) is present.
**Outcome**: The Models list is a flex child with overflow. Over-budget cards show Needs N GB VRAM instead of Compatible. Snapshot-selected missing tags show Retry copy. Packaged window scroll and a live Qwen 4B pull were not recorded this phase.

## 2. Chronological Steps

### 2.1 Scroll the Models list (T009)

**Plan specification**: List is a flex child with `flex: 1`, `minHeight: 0`, `overflowY: auto`. Nested parents from the Settings shell down to `ul` also get `minHeight: 0`.

**What happened**: `SettingsPage` shell uses `minHeight: 0` and `overflow: hidden`. `ModelsSettings` page, section, and list match that contract. Search is a static label, not a `flex: 1` sibling that ate the list.

**Key files changed**: `desktop/src/pages/settings/SettingsPage.tsx`, `desktop/src/pages/settings/ModelsSettings.tsx`

### 2.2 Badge and sort parity (T010)

**Plan specification**: Over-budget never displays Compatible. Sort Required, Recommended that fits, Compatible that fits, then over-budget. Within a group, `releaseDate` desc, missing dates last, then name.

**What happened**: Added `cardBadgeLabel`, `catalogSortRank`, and `sortModelsOnTab`. Required still wins even when over budget. Missing VRAM numbers leave the badge blank instead of inventing Compatible. SANA 1.6B 4K (`vramGB: 20`) on a 16 GB host is Needs 20 GB VRAM and sorts below a Recommended sprint card.

**Key files changed**: `desktop/src/shared/models/catalogTabs.ts`, `desktop/tests/catalogTabs.test.ts`

### 2.3 Installer card chips (T011)

**Plan specification**: Marshal origin, releaseDate, uncensored. Omit missing origin. Uncensored false shows Censored.

**What happened**: `ListedModel` and both DTO copies carry the three fields. Registry `list()` copies them from the catalog spec onto installed and catalog-only rows. Cards render Origin / Released / Censored|Uncensored chips.

**Key files changed**: `core/registry/NexusModelRegistry.ts`, `desktop/sidecar/src/models/modelsService.ts`, `desktop/src/pages/settings/modelsTypes.ts`, `desktop/src/pages/settings/ModelsSettings.tsx`

### 2.4 Qwen 3.5 4B residency (T013)

**Plan specification**: Downloaded iff the probe sees the tag or alias. Snapshot membership without tags is selected-but-missing plus Retry, not a silent Download.

**What happened**: `ModelsService.list` loads `~/.nexus/selected-models.json` (injectable in tests) and expands ids through `foldModelId` / `aliasesFor`. Selected missing rows keep Download as Retry. Installer snapshot writer keeps a ticked `qwen3.5:4b` even when 9B is also selected. Family collapse still hides siblings on the Qt wizard; Settings shows every catalog row and tells the truth from snapshot plus tags.

**Key files changed**: `desktop/sidecar/src/models/modelsService.ts`, `scripts/installer/tests/test_runtime_provisioner.py`

## 4. Decisions

- Badge Compatible requires a numeric VRAM comparison that fits. Unknown host or model VRAM is a blank badge, not Compatible.
- Snapshot membership is not proof of bytes. Downloaded still requires the installed probe.
- Tests that construct `ModelsService` inject `loadSnapshot` so CI never depends on the developer `~/.nexus/selected-models.json`.

## 5. Residual risk

- Packaged Explorer Settings scroll is unproven (DF-2).
