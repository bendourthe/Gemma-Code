## 2. Chronological Steps

### 2.1 Document OCR defaults

**Plan specification**: Add Document as multi-pick, use RapidOCR on CPU and 8 GB, and use Unlimited-OCR 3B on 12, 16, and 24 GB.

**What happened**: `SECTION_ORDER` and all five `recommended.json` tiers now include Document. Tests assert the exact low/high tier split and verify Document never joins `SINGLE_PICK_SECTIONS`.

**Key files changed**: `core/registry/recommended.json`, `scripts/installer/src/nexus_installer/tier_defaults.py`, `scripts/installer/tests/test_tier_defaults.py`

### 2.2 Transparent Windows taskbar tile

**Plan specification**: Prefer the no-background asset and stop filling the taskbar canvas navy.

**What happened**: `_render_taskbar_tile` paints on `canvas.fill(0)`, prefers `nexus-ai-primary_no-background.png`, and preserves `icon.png` as fallback. Pixel-level tests cover preference and alpha behavior.

**Key files changed**: `scripts/installer/src/nexus_installer/widgets/win_titlebar.py`, `scripts/installer/tests/test_win_titlebar.py`

### 2.3 Successful auto-advance and compact Complete

**Plan specification**: Auto-advance after success only, unpin the stepper, remove wasted margins, prevent label clipping, and shrink Copy locally.

**What happened**: `_on_install_finished(True)` schedules `_advance_to_complete`; false remains on Installing. Complete cards and rows are compacted, the service name width is 200px, and `_CommandRow` applies a local 24px Copy rule without touching the global button height.

**Key files changed**: `scripts/installer/src/nexus_installer/window.py`, `scripts/installer/src/nexus_installer/pages/complete.py`, `scripts/installer/tests/test_phase6_shell.py`, `scripts/installer/tests/test_complete.py`
