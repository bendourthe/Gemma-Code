## 2. Chronological Steps

### 2.1 One liquid-glass rail state

**Plan specification**: Stop consuming `entry.accentVar` in module NavLinks and use one frosted selected state for all four pillars.

**What happened**: Sidebar module rows receive `.nexus-nav-link`, inactive rows remain transparent, and selected rows get a hairline, inset highlight, blur, and neutral foreground. Icons inherit `currentColor`; the title-bar brand and module token catalog are untouched.

**Key files changed**: `desktop/src/components/Sidebar.tsx`, `desktop/src/styles/globals.css`, `desktop/tests/Sidebar.test.tsx`

### 2.2 Full-perimeter brand beam

**Plan specification**: Wrap the inner typing surfaces, remove the 48-degree breathing wedge and competing focus borders, and use brand cyan for every pillar.

**What happened**: MediaComposer and CodingInput place AccentBeam directly around their inner surfaces. Breathing uses a full solid masked ring with opacity pulse, traveling keeps the 360-degree sweep, drag uses `--accent-primary`, and send icons use `--fg-0`.

**Key files changed**: `desktop/src/shared/chat/MediaComposer.tsx`, `desktop/src/modules/coding/CodingInput.tsx`, `desktop/src/styles/globals.css`

### 2.3 Accessible studio icon actions

**Plan specification**: Replace native action captions with lucide icons while retaining accessible names and the existing test IDs.

**What happened**: RecallActions plus Image and Video page actions share `.nx-icon-btn`, `aria-label`, and `title`. Coding New session deliberately retires `coding-new-session-metal` in favor of a neutral glass `coding-new-session` control.

**Key files changed**: `desktop/src/shared/studio/RecallActions.tsx`, `desktop/src/modules/image/ImageStudioPage.tsx`, `desktop/src/modules/video/VideoLabPage.tsx`, `desktop/src/modules/coding/CodingPage.tsx`
