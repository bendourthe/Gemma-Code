## 2. Chronological Steps

### 2.1 Date + time + tokens (T006, T007)

**Plan specification**: Day heading `Weekday, Month Date, Year` in the user locale. Discrete time on every bubble. Tokens: user `N in`; assistant include reasoning in the number or `N think + M out` when both are known. Missing createdAt skips time. Streaming updates tokens on complete. Duplicate headings keyed by calendar day.

**What happened**: Added `transcriptChrome.ts` (`parseMessageTime`, `calendarDayKey`, `formatDateHeading`, `formatBubbleTime`, `formatBubbleTokens`, `isoTimestampFromMillis`). MessageList inserts a full-width separator when the local day changes. MessageBubble shows `<time>` plus tokens under the body. Chat `appendMessage` stamps live ISO time. Image/Video wrap new bubbles with `withLiveTimestamp`. Coding turns carry `createdAt` on live send/parse and persist it on sidecar `PersistedTurn` / resume DTO. Studio and chat hydrate skip epoch-zero millis.

**Key files changed**: `desktop/src/shared/chat/transcriptChrome.ts`, `MessageList.tsx`, `MessageBubble.tsx`, Chat/Coding/Image/Video pages, `studioSessionMemory.ts`, sidecar `sessionStore` / `sessionManager` / `protocol`.

### 2.2 Tests and CI

MessageList: two same-day turns => one heading; next day => second heading; epoch skips clock; tokens by role. Chat/Agents/Images/Videos smokes assert time and token testids after a turn. CI comment names day separators; no new jobs; no live GPU.
