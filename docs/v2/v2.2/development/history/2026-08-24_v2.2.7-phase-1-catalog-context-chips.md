## 2. Chronological Steps

### 2.1 Marshal contextWindow (T001)

**Plan specification**: Desktop list-models IPC includes `contextWindow` (number or null). Missing is null, not 0. Non-numeric junk skips the chip and logs once. Do not default Gemma's window onto other ids.

**What happened**: Added `core/registry/contextWindow.ts` (`parseContextWindow`, `catalogContextFromSpec`, `formatContextChip`). `NexusModelRegistry.list()` spreads catalog windows onto installed and catalog-only rows. Sidecar `toDto` copies them as null when absent. Optional `contextWindowIn` / `contextWindowOut` are marshaled when the catalog has them; they are not invented from a single window.

**Key files changed**: `core/registry/contextWindow.ts`, `core/registry/catalog.ts`, `core/registry/NexusModelRegistry.ts`, `desktop/sidecar/src/models/modelsService.ts`, `desktop/src/pages/settings/modelsTypes.ts`

### 2.2 Render on Settings and installer (T002)

**Plan specification**: Visible Context chip on both Models tabs as `128k` or `32k / 8k`. Do not append `in`. Independent of the Compatible badge. Every catalog row with numbers gets a chip, not only text models.

**What happened**: Settings `ModelCard` renders `formatContextChip(item)` after the origin chip. Installer `typed_catalog.py` parses with `parse_context_window` (0 means absent), formats with `format_context_chip`, and shows the chip on any row with a positive window (including document OCR 32k). Image fixtures with no window have no Context pill. Over-VRAM SANA still shows Needs VRAM, not Compatible.

**Key files changed**: `desktop/src/pages/settings/ModelsSettings.tsx`, `scripts/installer/src/nexus_installer/pages/typed_catalog.py`

### 2.3 Tests and CI (T002, 1.3)

ModelsSettings: LFM 128000 -> `Context: 128k`; split -> `32k / 8k`; gemma without a field and ltx-video / SANA 4K omit the chip. NexusModelRegistry list + ModelsService toDto round-trip. Installer load + Qt card tests. CI comments name the v2.2.7 chip contracts; installer-tests path filters already cover `scripts/installer/**`.
