## 2. Chronological Steps

### 2.1 Shared meter + picker row (T005)

**Plan specification**: Pill `ContextUsageBar` under ChatPage, CodingPage, ImageStudioPage, VideoLabPage. `QuickModelSwitcher` immediately to the right. Wire `sessionContextUsage`. At >= 80%, suggest starting a new session. Do not auto-clear history. Peeking another tab must not load weights. Remove the root-only `/` breadcrumb and unicode gear; keep persona reachable.

**What happened**: Added `ContextUsageBar`, `ComposerContextRow`, and `composerSessionUsage`. Display percent uses `Math.floor(percent + 1e-9)` so float 79.9 does not paint as 80 before `atOrAbove80`. Moved Chat/Agents pickers out of the header. Images/Videos now use `QuickModelSwitcher` with the existing `image-model-select` / `video-model-select` testids (installed-and-ready filter, same as Chat/Agents). Chatbot CTA calls `createChat` in the same folder and selects it; Agents CTA reuses `handleNewSession` (clears local turns, does not delete the persisted session); Images/Videos create a new studio session and leave the old one in `StudioHistoryPane`. Persona is a footer "Persona" button (`chat-persona-toggle`), not a header gear.

The meter does not call `residency.request`.

**Key files changed**: `desktop/src/shared/chat/ContextUsageBar.tsx`, `ComposerContextRow.tsx`, `usageTurnsFromMessages.ts`, `ChatPage.tsx`, `CodingPage.tsx`, `ImageStudioPage.tsx`, `VideoLabPage.tsx`.
