## What was implemented

- **1.1 (T001)**: The voice capture indicator renders only while `voiceLoop.captureVisible` is true (copy: "Recording -- microphone is open"); the idle composer shows no "Mic closed" element at all. The always-visible Persona footer button was removed; Persona now lives in a composer overflow ("...") menu (keeps test id `chat-persona-toggle`) and `chat.explorer.setPersona` still works. Agents untouched (they do not share this footer).
- **1.2 (T002)**: `ContextUsageBar` grows (`flex: 3 1 auto`); the picker sits in a bounded slot (`flex: 0 1 30%`, `max-width: 30%`, `min-width: 14rem`) on a `nowrap` `ComposerContextRow`; long model names ellipsize with a `title` tooltip. Shared row on all four tabs; `denominatorKind: "none"` still renders no bar.
- **1.3 (T003)**: `BubbleMeta` moved above the message body and is skipped entirely on pending rows (no clock, no em dash; `UNKNOWN_TOKEN_MARK` removed). New token copy: `1 input token` / `N input tokens`; `171 tokens (75 reasoning + 96 output)`; `N output tokens` / `N reasoning tokens`; unknown counts omit the span. ASCII only.
- **1.4 (T004)**: Selected FolderTree row uses `color-mix(in srgb, var(--fg-0) 12%, transparent)` plus a 4px accent left bar and `aria-selected` (never `--bg-1` on a `--bg-1` pane). `StudioHistoryPane` takes `activeSessionId` and both studio pages bind it to the open session.
- **1.5 (T005)**: First send on a still-default chat immediately persists `fallbackTitle(prompt)` via `renameChat` (byUser false) and bumps the FolderTree refresh; `generateTitle` fires after the first assistant turn resolves and renames only if `userRenamed` is false. Sidecar `chat.generateTitle` persists through explorer rename (new `getChat` op guard). FolderTree inline rename passes `byUser: true`. Empty prompt keeps "New chat".
