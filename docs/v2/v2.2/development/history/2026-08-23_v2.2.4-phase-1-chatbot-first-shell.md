## 2. Chronological Steps

### 2.1 Cold-start Chatbot

**Plan specification**: Every new renderer process opens `/chatbot`. Chatbot thread sub-paths may still restore.

**What happened**: `normalizeActiveRoute` now returns the stored value only for `/chatbot` and `/chatbot/...`. All other stored routes, including `/settings/models`, map to `/chatbot`. `main.tsx` comments match that policy. In-session `writeActiveRoute` is unchanged so Ctrl+2 still opens Agents after first paint.

**Key files changed**: `desktop/src/lib/persistence.ts`, `desktop/src/main.tsx`, `desktop/src/App.tsx`

### 2.2 Tab labels

**Plan specification**: Chatbot, Agents, Images, Videos. Keep routes unless a rename is cheaper.

**What happened**: `MODULES` labels changed. Routes stayed `/chatbot`, `/coding`, `/images`, `/videos`. Module cards and nav aria-labels pick the new copy from the registry.

**Key files changed**: `desktop/src/types/modules.ts`

### 2.3 Edge collapse pill

**Plan specification**: Do not render collapse as the first flex child. Pill on the vertical center of the aside's right edge. Keep `data-testid="sidebar-collapse-toggle"`.

**What happened**: The module nav is the first element child. The toggle is an absolutely positioned pill with ChevronLeft when expanded and ChevronRight when compact. Aside overflow is visible and z-index sits above main so the pill is not covered.

**Key files changed**: `desktop/src/components/Sidebar.tsx`, `desktop/src/styles/globals.css`

### 2.4 Tests

**Plan specification**: Persistence, App, Sidebar, shell-phase6, ModuleCard.

**What happened**: Restore matrix now asserts last-module routes become `/chatbot`. Label assertions use Chatbot. Sidebar tests assert the nav is the first aside child and the pill toggles without changing the active module.

**Key files changed**: `desktop/tests/persistence.test.ts`, `desktop/tests/App.test.tsx`, `desktop/tests/Sidebar.test.tsx`, `desktop/tests/shell-phase6.test.tsx`, `desktop/tests/ModuleCard.test.tsx`

## 4. Decisions

- Last-module restore is a product reversal, not a missing default. Session navigation after first paint still works.
