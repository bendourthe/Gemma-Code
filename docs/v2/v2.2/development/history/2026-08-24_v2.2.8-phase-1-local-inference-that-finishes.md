## 2. Chronological Steps

### 2.1 Streaming-safe RPC timeouts (T001, T002)

**Plan specification**: Long-running methods do not share `RPC_TIMEOUT_DEFAULT`. Chat/coding/image/video send or generate stay open for the event stream. Ping stays 15s. Malformed names stay 15s. Sidecar exit mid-stream stays `Exited`. Concurrent ping during generate stays 15s.

**What happened**: Added `RPC_TIMEOUT_INFERENCE` (600s) for exact method names including plan alias `chat.send` and the real `chat.session.sendMessage`, `coding.session.sendMessage`, `coding.startTask`, `image.generate`, `video.generate`, and the diffusion generate methods. Cap hits return typed `SidecarError::Request` copy, not `Timeout`. Chat, Agents, Image, and Video surfaces rewrite a leftover timeout string through `formatChatTurnError` / `formatInferenceError`.

**Key files changed**: `desktop/src-tauri/src/sidecar.rs`, `desktop/src/lib/inferenceRpcError.ts`, `desktop/src/modules/chat/ChatPage.tsx`, `desktop/src/modules/coding/CodingPage.tsx`, `desktop/src/modules/image/ImageStudioPage.tsx`, `desktop/src/modules/video/VideoLabPage.tsx`

**Troubleshooting**: None. Compile and tests passed on the first run.

**Verification**: `cargo test rpc_timeout` 3 passed. ChatPage slow-stream and timeout-rewrite tests passed.

### 2.2 Installed Gemma is Downloaded (T003)

**Plan specification**: Packaged Settings treats alias-folded Ollama tags as installed. Unknown tags do not map onto Gemma. Snapshot-selected missing stays Retry. Ollama down does not crash.

**What happened**: `queryOllamaTags` collects both `name` and `model`. `ollamaTagsIncludeModel` matches catalog id `gemma-4-12b-it-gguf` to tag `gemma4:12b` via aliases/`foldModelId`. `createModelsRuntime` honors `NEXUS_OLLAMA_URL`. ModelsSettings shows Downloaded when `installed && source !== catalog-only`.

**Key files changed**: `core/registry/installedProbe.ts`, `desktop/sidecar/src/models/modelsService.ts`, `desktop/tests/installedProbe.test.ts`, `desktop/tests/modelsService.test.ts`, `desktop/tests/ModelsSettings.test.tsx`

## 5. Plan Discrepancies

- The plan names `chat.send`; the live IPC method is `chat.session.sendMessage`. Both are minutes-class so the stability gate and the real path match.
- Concurrent ping during generate is asserted as `ping` 15s and generate 600s, not a spawned sidecar integration.

---

## 6. Assumptions Made

- A 10-minute cap is long enough for a cold Gemma 4 12B first token on a laptop GPU and still bounds a hung generate.
- Drain-event polls stay at 15s because they return buffered events; generate accept/send is the long wait.
- Collecting Ollama `/api/tags` `model` in addition to `name` is safe and does not invent Compatible.
