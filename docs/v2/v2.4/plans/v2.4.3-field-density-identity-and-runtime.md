## Overview

v2.4.2 landed on this packaged host: history lives in the left sidebar, Unsloth shows an Incompatible badge, VS Code sits on Configuration, video fails with a written error, Settings no longer prints a catalog hash, and delete copy is generic. The same pass still wastes vertical space on installer pages, lets Unsloth stay ticked while labelled Incompatible (the badge is computed at page construct, before GPU detection finishes), leaves Image sessions titled "New chat", reprints the tan puppy at img2img strength 0.45, clips the Searching glow, parks the delete dialog in the sidebar, wraps Settings pills, shuffles the Agents picker, and probes SANA-Video as if it were a complete Wan Diffusers tree.

This plan is a second field pass on `feat/v2.4.1-field-reliability`. It does not reopen the v2.4.2 sidebar host, empty-video honesty gate, or VS Code merge. Phase 1 fixes installer layout and Unsloth lock. Phase 2 fixes history chrome, new-chat selection, first-send titles, and the delete overlay. Phase 3 fixes the thinking pill. Phase 4 densifies Settings cards. Phase 5 shares picker order and default. Phase 6 raises restyle identity. Phase 7 gives SANA-Video a real layout and executor. Phase 8 is the mandatory fail-closed closeout.

No phase except the last pushes, opens a pull request, or starts remote CI. Each earlier phase ends with automated tests, session history, and one local commit. v2.4.2 T043 remains a separate publication hold.

## Architecture Decisions

1. **Unsloth Incompatible is not selectable.** v2.4.2 AD allowed opt-in after a warning. Screenshot 1 reverses that: if the badge is Incompatible, the checkbox is disabled and cleared. Refresh the badge on `showEvent` so it is not computed at construct with `vram_mb=0`. Host-ok is NVIDIA plus `display_vram_gb(vram_mb) >= 16` (the 15 GiB-class band still counts as 16). This 16 GB laptop must show Compatible.
2. **Installer summaries are two columns.** Configuration: Components left, Features right. Review: install path, components, GPU, disk, estimated installation time on the left; the model list on the right. GPU on Review uses `display_vram_gb`, never raw MB.
3. **Delete and archive dialogs portal to `document.body`.** `position: fixed` inside the sidebar history host is why screenshot 6 sits flush left and clips. Center over the full window.
4. **New chat selects.** `FolderTree.onCreateChat` calls the same `onSelect` path as a row click and shows an empty transcript. Creating a session is not enough.
5. **Untitled sessions title on first send.** Image/Video `ensureSession` returns early when a "New chat" row already exists, so `titleJobRef` never runs. Chat already titles on first send of an untitled chat. Studio must do the same, including `applyImmediateFallbackTitle` plus `refineGeneratedTitle`.
6. **Thinking pill width is constant.** Min-width is the longest caption (`Searching...`) plus orb and padding. Add left inset (or host margin) so `box-shadow` / drop-shadow is inside the transcript, not against the pane edge.
7. **Settings facts are one nowrap row.** Origin / license / long metadata move into Details. The dense row keeps size, VRAM compatibility, and recommendation. Actions are icon-only: green Downloaded, red trash Remove, blue Download.
8. **Picker order is installer recommend order.** `QuickModelSwitcher` today lists `visibleModelsOnTab` without `hostVramGB` or `recommendOrder`, so Agents looks shuffled and can default to gpt-oss 20B. Pass host VRAM, sort with `catalog_tab_sort` / snapshot `recommendedByTask`, and default an empty session to the installer required/recommended id for that task. A later user change still sticks on that session.
9. **Whole-image restyle uses stronger img2img.** "Make the puppy black" already parses as `scope: "image"`. Strength 0.45 preserves tan fur. Restyle strength is 0.70 (object inpaint stays 0.45). The img2img prompt must say keep composition and change fur color. Fail closed if `lastOutputRef` is missing (do not silently txt2img).
10. **SANA-Video is not Wan.** `sana_video.py` calls `real_execute.video_execute`, which requires `model_index.json` and `WanPipeline`. Catalog `sana-video-2b-720p` only lists transformer shards. Expand the weights manifest (or snapshot) for a complete Diffusers SANA-Video tree, and execute with the SANA-Video pipeline class, not Wan. 16 GB default video remains `wan2.1-t2v-1.3b`; this phase still has to make the opted-in SANA id honest.
