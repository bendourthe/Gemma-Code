## Overview

This plan turns the comparison's highest-value local capability into a Nexus feature. Image Studio gains a 3D preview path: a Nexus-owned WebGL viewer for local `.splat` and `.ply` files, then an optional feed-forward generator behind a backend-neutral contract. The first generator adapter may call MIT-licensed TripoSplat weights on NVIDIA CUDA after a capability preflight. Photos never leave the machine. The original 2D file stays downloadable. Copy must say object-level 3D preview, not a photorealistic property tour.

The plan also closes the Unsloth Qwen question without expanding catalog scope. Unsloth's 72.5 GB GGUF and thinking-control docs do not flip the v2.3.0 admission gates: the RAM floor is still about 75 GB, the published file list still omits `LICENSE`, the architecture is still `qwen4exp`, and Nexus tool-calling evidence is still absent. v2.4.0 records that Unsloth delta and keeps every installer and Settings surface free of Flash-Next. Qwen `chat_template_kwargs` / `reasoning_effort` plumbing stays deferred until some Qwen thinking artifact actually clears admission.

Success is a packaged local viewer with optional generate, automated contract/queue/UI/metadata evidence, and a fail-closed catalog. Human perceptual review and NVIDIA-only generate checks wait until the mandatory final phase.

## Goals First

**Target problem**: Users can generate a private 2D image but cannot inspect it as an orbitable 3D preview inside Nexus, while cloud splat tools and oversized experimental LLMs create pressure to add uploads or unlistable models.

**Target persona**: A privacy-focused developer or creator on a consumer Windows, Linux, or macOS computer who wants honest local 3D preview from an Image Studio still, without sending photos to a host and without being told a laptop can run a 75 GB Qwen4-exp checkpoint.

**Observable definition of done**: Image Studio opens a local `.splat` or `.ply` and orbits it offline; a supported NVIDIA host can optionally generate a splat from a completed or uploaded still as a cancellable child job; the 2D original remains intact; unsupported hardware fails closed with actionable copy; Unsloth Qwen3.8-Flash-Next is absent from user-facing catalogs; and no 3D AI Studio URL, API key, or credit flow exists.

**Strategy grounding**: No `STRATEGY.md` or version-scoped strategy anchor exists. The scope is grounded in AGENTS.md local-first product identity, the MCP Registry Policy (no generation-as-a-service), and the seeding comparison. No `docs/solutions/` store exists, so no solved-problem entry changed the phase design. Open v2.2 known gaps (packaged field QA DF-36, live GPU generate DF-4, raw Tauri Node DF-38, per-phase coverage MT-4) are ingested as last-phase reconciliation work, not as this feature's scope.
