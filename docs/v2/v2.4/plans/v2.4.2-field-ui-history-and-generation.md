**Goal**: After one send, the user always sees the latest turn, a concise session title, honest context, and a truthful result or error, while history lives under the four module tabs and installer GPU / Unsloth / VS Code choices match the rest of the product.

## Overview

v2.4.1 made image generation work on this host, but the same packaged pass still wastes a second history column, clips the thinking pill, names chats after the raw first prompt, and treats studio follow-ups as new txt2img jobs. Video can finish as an empty assistant bubble with no error. Settings still shows an internal catalog fingerprint and tall model cards. The installer still truncates VRAM and hides Unsloth compatibility behind a late warning, with VS Code on its own wizard step.

This plan is a field-driven UI and generation-follow-through cycle, not a rewrite of the v2.4.1 runtime lease or catalog pins. Phase 1 moves history into the left sidebar and fixes chrome that every tab inherits (thinking inset, scrollbars). Phase 2 makes transcripts honest (auto-scroll, context copy, titles, delete). Phases 3-4 close image edit identity and silent video failure. Phase 5 densifies Settings Models. Phase 6 finishes installer display and merges VS Code onto Configuration. Phase 7 is the mandatory fail-closed closeout.

No phase except the last pushes, opens a pull request, or starts remote CI. Each earlier phase ends with automated tests, session history, and one local commit.

## Goals First

**Target problem**: The packaged studio still spends horizontal space on a second history rail (or a horizontal Agents band), clips pending status, names chats after the first prompt, and fails follow-up image and first video turns without a usable explanation.

**Target persona**: A privacy-focused Windows user with a single consumer NVIDIA GPU who expects Chat, Agents, Images, and Videos to share one left pane, keep the latest turn in view, and either edit the last image or say why they cannot.

**Observable definition of done**:

- History for Chat, Agents, Images, and Videos is an independent segment of the left sidebar under the four module tabs and swaps with the active module. The main pane is transcript or workspace only.
- The thinking pill's orb is fully visible (no left crop) at default zoom, 100-200% zoom, and with history expanded or collapsed.
- After the user sends on any of the four tabs, the transcript sticks to the bottom unless they have scrolled up to read earlier turns. A new send from the composer always jumps to the latest turn.
- App scrollbars use a transparent track and a thumb that matches the dark scheme.
- Image follow-up "Make that puppy black" (no re-attach) edits the last generated image rather than sampling a new dog. Missing SAM2 does not dead-end: the bubble offers in-product install or paint-mask, and whole-image restyles fall back to img2img.
- A video turn that cannot produce a playable clip never paints an empty success bubble; it shows the real failure.
- Delete copy is generic ("Delete the selected chat(s)?") with the irreversible warning on its own line. Multi-select of chats and folders is supported.
- Session titles are a short model-generated name from the first prompt. The raw prompt is not the durable title.
- Settings Models has no catalog hash under the title, category tabs sit close to the title, and model rows keep every fact with tighter spacing.
- Installer GPU VRAM displays as a whole number rounded up (16 GB, not 15.x). Unsloth shows Compatible / Incompatible like model cards. The VS Code extension checkbox lives on the Configuration page; the separate VS Code wizard step is gone.

## Architecture Decisions

1. **Sidebar history host supersedes v2.4.1 AD-8.** History is not a second full-width rail and not a horizontal band in the main pane. It is a pillar-scoped segment of the single left sidebar, directly under Chatbot / Agents / Images / Videos, swapping as the module changes. Settings and Approvals stay at the foot. Compact icon-rail mode may hide titles; default for module routes is wide enough to read session names.
2. **Studio context is a session visual budget, not `maxImages: 1`.** Catalog `maxImages` remains a per-request encoder cap. The footer bar must not jump to 100% after one puppy PNG and 200% after the edit. Warning copy must match the number on the bar.
3. **Follow-up without an attachment uses the last usable output as img2img.** Object-local replace / remove still may call SAM2. Phrases like "make that puppy black" are whole-image restyles and must not require SAM2. When SAM2 is actually required and missing, the bubble offers install `sam2:hiera-tiny` or paint a mask; it never looks like success.
4. **Titles are generated, not sliced prompts.** Create the session as "New chat" (or equivalent), fire `chat.generateTitle` in the background from the first user prompt, then rename unless the user already renamed. Truncated-prompt fallback is only for timeout or no resident model.
5. **Empty media bubbles are errors.** Assistant turns with `pending: false`, no playable `media`, and empty `content` are forbidden. Persist the error string.
6. **Installer VRAM ceil is display-only.** `math.ceil(vram_mb / 1024)` for human-facing GPU labels. Tier selection and compatibility math keep the existing fractional GB path so a 15.4 GB part does not silently become a 16 GB tier.
7. **VS Code joins Configuration.** `STEP_NAMES` drops the "VS Code" step. Detection, checkbox, and unsupported-CLI copy move onto the Configuration page with Unsloth. Provisioning behavior does not change.
8. **One scrollbar grammar.** Transparent track, scheme-matched thumb, no opaque OS chrome. Tokens live in desktop CSS and apply to transcript, Settings, and other overflow panes.
