## Checklist

1. **Clean install progress**: Start the frozen installer on a clean Windows host. Confirm the overall bar is visually larger than phase bars, shows a live percentage, keeps the filled segment stationary and pill-shaped, moves one broad liquid-glass highlight smoothly through that fill over about 12 seconds, never decreases, reaches 100%, and remains understandable with Windows reduced motion enabled.
2. **Repair install progress**: Run the same artifact over an existing Nexus install. Confirm the same progress hierarchy and that retained/repair steps do not trigger the old `unsloth-pins.json` FileNotFoundError. Save `Downloads/nexus-install-nexus-desktop-log.txt`.
3. **Optional Unsloth**: Repeat with Unsloth enabled on a supported NVIDIA host. Confirm the pinned manifest is present in the frozen artifact, provisioning is opt-in, and failure is contained in the wizard with a retryable summary.
4. **SANA and CUDA runtime**: Select SANA/image support. Confirm the diffusion venv is created or repaired, its readiness response reports CUDA torch available, and Image Studio generates one real PNG. Record Python, torch, CUDA, model id, and elapsed time.
5. **Pending and response bubbles**: In Chatbot and Agents, send a message. Confirm the generating animation appears directly on the transcript canvas without a bubble; only the completed assistant response receives a bubble. Confirm user and assistant bubbles use subtly different backgrounds.
6. **Token and reasoning metadata**: Confirm time is left-aligned, `(X tokens)` is italic and right-aligned, hover and keyboard focus reveal input/reasoning/output counts, and a thinking-capable model shows a collapsed reasoning disclosure above the answer bubble that expands and collapses without mixing reasoning into the answer.
7. **Archive/delete matrix**: For Chatbot, Agents, Images, and Videos, delete one active session and archive another. Confirm both actions warn that the active view will reset, delete warns it cannot be undone, archive is reversible, late generation events do not repopulate the reset view, Settings > Archived chats groups by pillar, and Restore returns the session.
8. **Models and storage**: Compare installer and Settings model roster/order. Confirm downloaded cards use a restrained highlight, every catalog card shows a one-sentence description, size appears as a pill, VRAM appears beside compatibility, expanded details add information, and external weights stay in a separate honest group. Record the disk meter before install, after install, and after remove.
9. **Multi-root Agents workspace**: Confirm first launch defaults to the OS home directory. Replace the primary root, add a second root, cancel a picker without changing state, remove an extra root, and restart the app to prove persistence. Create a session, read/write inside both roots, attempt and observe denial outside both roots, then verify history groups the session under `Primary +1` with full-root tooltip. Confirm changing roots during an active run requires stop-and-switch confirmation.
10. **Gated Hugging Face model sign-in**: Select a gated model, accept its publisher terms in the browser, then use `Sign in with Hugging Face`. Confirm browser device authorization returns to the installer, validates repository access, and continues without copying a token. Confirm manual read-token entry and `Skip this model` remain usable fallbacks.
