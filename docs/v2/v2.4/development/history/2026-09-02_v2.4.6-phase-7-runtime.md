## 2. Chronological Steps

### 2.1 Gutters and assistant tokens (T032, T033)

**What happened**: `MessageList` already used one list `paddingInline` of `TRANSCRIPT_GUTTER_PX` (12). No extra pill margin. `persistMessage` forwards `requestUsage` and `messageUsage`. Assistant complete prefers provider `outputTokens`, else `estimatedMessageUsage`. Stop increments a turn epoch so a late reply cannot overwrite the stopped bubble. ChatPage tests assert the assistant `message-tokens-` node.

### 2.2 Allowlist then recommend order (T034, T051)

**What happened**: `ownedIdSet(null)` is an empty set. `installedForTask` / `installedModelsForType` never treat a missing snapshot as pass-through. `recommendOrderForTask` is recommended id, then `orderedIds`, then `downloadedSinceInstall`. QuickModelSwitcher filters owned intersect catalog tab and sorts by that order. `hostVramGB` is accepted but unused so a missing VRAM reading cannot shuffle owned rows. Chat/Agents/Image/Video always pass `ownedIds={ownedIdSet(selection)}`. Image/Video ipc-unavailable fallbacks own the sentinel id through `snapshotForOwnedIds` so FALLBACK_MODEL cannot appear while the sidecar is up.

### 2.3 Stop, captions, Advanced, Image default (T035-T038)

**What happened**: `MediaComposer` and `CodingInput` replace Send with Stop while streaming (`media-composer-stop`, `coding-input-stop`). Image/Video cancel the queue job and patch pending to Stopped. `mapping.ts` image/video labels are Creating and Generating; orb `state` remains `shaping` (animation enum). Advanced lives in `ComposerContextRow` `trailing` (`composer-advanced-slot`). Image default uses `recommendedByTask.image`. A 16 GB snapshot that owns both Juggernaut and RealVis selects `realvisxl-v5` and lists RealVis first.

Juggernaut is catalog id `juggernaut-xl-v9`. The wizard can auto-tick it because those weights were already on disk. That is not a ghost picker row. It appears in Chat/Agents/Image/Video only when it is in `orderedIds` or `downloadedSinceInstall`.

### 2.4 GPU busy (T039)

**What happened**: `queryHostGpu` retries `C:\Windows\System32\nvidia-smi.exe` on Windows after PATH `nvidia-smi` fails. `createLiveTelemetryStream` polls the scheduler snapshot. `idle` is false whenever `active` is non-null, including utilization 0%. Chat and Agents `sendMessage` wrap work in `scheduler.enqueue` (`jobType: "tokens"`). Composer Context 0% on an empty session is unchanged.

### 2.5 Tests (T040)

**What happened**: `owned-picker-allowlist.test.tsx` hides leftover LLM/image ids from all four pickers, pins Gemma 4 12B before gpt-oss on Agents, and still shows unowned catalog cards in Settings. ImageStudioPage pins RealVis default. gpu-runtime, live-telemetry, telemetryStream, and GpuStatusFooter pin System32 fallback and Busy at 0%. Fail-closed fixtures add `lastSelection` wherever a picker must list a model.
