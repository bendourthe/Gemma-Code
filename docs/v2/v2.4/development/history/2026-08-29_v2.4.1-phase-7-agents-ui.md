# Development Log: Agents Workspace and History Experience

**Date**: 2026-08-29
**Operator**: Benjamin Dourthe
**Assisted by**: Codex, GPT-5.6-sol
**Outcome**: Phase 7 is complete at the internal-compatible support tier. Agents now uses native folder selection, durable multi-root workspace chips, workspace-grouped history, and a simplified Chat, Memory, and Activity navigation model.

## Implementation

- Replaced the raw workspace path input with a primary folder chip, an add-folder action, removable additional chips, full-path tooltips, and native multi-directory selection. First launch resolves the operating-system home directory, structured workspace state migrates the legacy primary path, malformed JSON falls back safely, and the selected primary always renders first.
- Preserved root snapshots for active sessions. Idle workspace changes cancel and reset the old session before applying; busy changes explain that the running session is fixed to its roots and require explicit stop-and-switch confirmation. Canceled, malformed, duplicate, slow, and stale picker results cannot clear or widen the current workspace.
- Sent `workspaceRoots` and `primaryRoot` on every new coding session while retaining `workspacePath` for the compatibility window. Resuming a session restores its durable workspace selection.
- Replaced browser-only workspace grouping with top-level directories derived from persisted workspace identity. Labels use the primary folder plus `+N`, full roots appear on hover, and current workspace nodes expand on load. Legacy unscoped sessions and existing local folders migrate without loss under `Legacy workspace / Unsorted`.
- Made Agents workspace directories immutable while retaining session open, rename, archive, and permanent-delete controls. Chatbot and Studio folder behavior is unchanged.
- Removed the redundant Sessions tab, migrated legacy `sessions` links to Chat and `trace` links to Activity, added explanatory tab tooltips, and added workspace-scoped Memory and runtime-focused Activity descriptions.
- Updated stale cross-phase catalog fixtures with the canonical model `task` field and moved Archived Chats retry/restore actions onto the shared Settings Button component. These changes restore full-suite parity for the Phase 4 and Phase 5 contracts.
