## 2. Chronological Steps

### 2.1 Sidebar history host (T001-T004)

**Branch**: `feat/v2.4.1-field-reliability` | **PR**: none | **Merged to**: n/a

**Plan specification**: One left pane owns module nav plus a history slot. Chat `FolderTree`, studio history, and Agents sessions fill that slot. Settings and Approvals show no slot. Compact icon-rail hides titles and must not open a second column.

**What happened**: Added `SidebarHistoryProvider` and `SidebarHistorySlot` (`createPortal` into a host under `sidebar-module-nav`). Module routes default expanded at 280px. Chat, Image, Video, and Agents register existing trees. Removed `CollapsibleHistoryAside`. Pages rendered without App keep an in-place fallback so unit tests still see `chats-pane` / `coding-history-pane`.

**Key files changed**: `desktop/src/components/SidebarHistoryHost.tsx`, `desktop/src/components/Sidebar.tsx`, `desktop/src/App.tsx`, `desktop/src/modules/chat/ChatPage.tsx`, `desktop/src/modules/coding/CodingPage.tsx`, `desktop/src/shared/explorer/StudioHistoryPane.tsx`, `desktop/src/modules/image/ImageStudioPage.tsx`, `desktop/src/modules/video/VideoLabPage.tsx`

**Troubleshooting**:
- **Problem**: `shell-phase6.test.tsx` still expected the compact-by-default rail (`nav-chatbot` text empty).
- **Root cause**: Phase 1 changed the no-preference default to expanded so session titles fit.
- **Resolution**: Updated those tests to the new default and stored-compact behavior.

**Verification**: `npx vitest run tests/sidebar-history-host.test.tsx` 8 passed.

### 2.2 Uncrop thinking pill (T005)

**Plan specification**: Left dots of the 48px bubble orb must sit inside the visible pill. Do not wrap pending status in a message bubble.

**What happened**: Pill chrome is a sibling layer with `border-radius: 999px`. The host uses `overflow: visible` and no capsule radius. Canvas stays a direct child.

**Key files changed**: `desktop/src/components/agentState/AgentStateOrb.tsx`, `desktop/src/components/agentState/orbEngine.ts`

**Verification**: AgentStateOrb and sidebar-history-host geometry tests passed. jsdom cannot prove real pixels (known-gaps MT-1).

### 2.3 Scrollbar tokens (T006)

**Plan specification**: Transparent track, scheme-matched thumb, `::-webkit-scrollbar` plus `scrollbar-color` / `scrollbar-width`.

**What happened**: Shared tokens in `desktop/src/styles/tokens.css`.

**Verification**: Token file assertions in `desktop/tests/sidebar-history-host.test.tsx`.

### 2.4 Testing and stabilization (T007-T008)

**What happened**: New host tests plus updates to Chat, Studio, Coding, Sidebar, and shell-phase6 tests. Deleted unused `CollapsibleHistoryAside.tsx`.
