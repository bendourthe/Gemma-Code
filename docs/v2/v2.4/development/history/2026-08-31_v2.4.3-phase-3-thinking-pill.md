## 2. Chronological Steps

### 2.1 Fixed width and inset (T013)

**What happened**: `longestPendingCaption()` and `pendingPillMinWidthExpr(orbPx)` live in `captionRotator.ts`. Rotating pills set `minWidth` to that expression, `marginLeft` to `PENDING_PILL_INSET_PX` (12), and keep `overflow: visible`. The caption span also uses the longest caption in `ch` so the word column does not shrink. `PendingMessage` adds the same inset as left padding so the glow is not flush to the pane.
