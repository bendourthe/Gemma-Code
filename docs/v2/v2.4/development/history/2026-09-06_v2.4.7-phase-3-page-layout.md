## 2. Chronological Steps

### 2.1 Browse inside a full-width path field (T011)

**What happened**: The field and the button shared a `QHBoxLayout`, so the button's width came out of the field's. The field now takes the whole row and Browse is an overlaid child positioned against its right edge, repositioned on `resizeEvent` and `showEvent`.

`setTextMargins` keeps typed text clear of the button, which is the part that would otherwise look fine at the default width and break on a long path. The field stays editable and the button stays focusable and clickable; both are asserted rather than assumed.

### 2.2 Ollama URL in the components column (T012)

**What happened**: The field was added to the page layout after the two-column split, so it spanned the full page under both columns. It now lives in the components column directly beneath the Ollama row, at column width.

The visible "Ollama URL" heading is gone, as requested. The meaning moves to `accessibleName` plus a placeholder carrying the default, so the field is still identifiable to a screen reader and to a user who has not seen it before. `_url_input` is kept as an alias for the moved widget so any caller reaching for it by name keeps working.

The field is hidden when the selection does not require Ollama, which Phase 2 made knowable. A URL for a daemon that will not be installed is noise.

### 2.3 Drop the VS Code detection paragraph (T013)

**What happened**: The compact row now shows the checkbox alone. Detection itself is unchanged and still drives the checkbox's enabled state.

The paragraph is hidden rather than deleted, and its text becomes the checkbox's tooltip when the extension cannot be installed. Removing the text outright would have removed the only explanation a user gets for a disabled control, which trades one problem for a worse one.

### 2.4 Testing and stabilization (T014)

**What happened**: Seven cases in `TestWizardDensityV247` cover the overlaid Browse and its text margin, the field staying editable, the disk and error lines surviving, the URL's parent and accessible name with the heading absent, the URL hidden when Ollama is not required, the hidden detection paragraph, and the tooltip standing in for it when the checkbox is disabled.

One test failed on a missing `QLabel` import in the new class; the file imports it locally per test, so the import moved inside.
