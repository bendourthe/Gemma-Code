## 2. Chronological Steps

### 2.1 Two-column prerequisites and refresh icon (T006, T007)

**What happened**: Compact `PrerequisitesPage` puts VS Code and Python on row 1, Disk and Ollama on row 2. Width below 520 px restacks to one column. Re-check is a title-row `QToolButton` (`↻`) with accessible name and tooltip `Re-check`. The full-width `SecondaryButton("Re-check")` remains only on the standalone page. A second click disconnects, quits, and waits on the previous detection worker before starting a new one.

### 2.2 One-line GPU card and packed Setup spacing (T008, T009)

**What happened**: Compact GPU card padding is 8 px. On detect, one `QLabel` shows `{name} | Vendor: {Vendor} | {display_vram_gb} GB VRAM`. Long names elide with a full-string tooltip when the label is at least 80 px wide; narrower labels keep the full text so unshown widgets do not collapse to ellipses. No GPU hides the card and keeps the warning status line. Compact mode hides the recommended-model callout. `SetupPage` spacing is 6 px with no trailing stretch. Install path and the available-space caption stay.

### 2.3 Testing (T010)

**What happened**: `test_pages_qt.py` asserts no compact `QPushButton` text `Re-check`, one `QToolButton` named `Re-check`, two-column then stacked grid, worker replace, one-line GPU including vendor and VRAM, hidden GPU card on miss, elision, and no trailing stretch.
