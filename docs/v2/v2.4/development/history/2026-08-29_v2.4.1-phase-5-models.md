# Development Log: Canonical Model Library and Disk Meter

**Date**: 2026-08-29
**Operator**: Benjamin Dourthe
**Assisted by**: Codex, GPT-5.6-sol
**Outcome**: Phase 5 is complete at the internal-compatible support tier. The installer and Settings consume the same validated catalog, show every selectable row in the same deterministic order, retain incompatible choices, separate discovered external installs, and expose the same full-catalog fingerprint. Settings cards use a quieter downloaded state and a live accessible model-storage meter.

## Implementation

- Added a canonical TypeScript display policy and mirrored Python policy: task-bearing non-external rows only, required then recommended then compatible, release date descending, and case-folded name/id fallback. Family collapse, VRAM hiding, and downloaded-first reordering no longer affect the primary roster.
- Added cross-language canonical SHA-256 catalog fingerprints and verified the shipped catalog resolves to `acb3e4e00370c2fa74e9a7b5e54a3d86cb117c19ca88f81d50e8aba0edc0c0b8` in both runtimes.
- Enforced a complete-sentence description for every selectable catalog row in both catalog validators.
- Reworked Settings cards to keep descriptions visible, move size and compatibility into pills, remove the raw id/task/size/VRAM summary, place technical facts and family-linked VAE/ControlNet components in Details, and replace the green downloaded wash with a muted status and subtle edge indicator.
- Reworked installer ordering and facts to match Settings, keep incompatible models visible but disabled, and preserve checked ids while rendering all family variants. The card flow-layout golden test covers 900 px and 360 px header widths.
- Extended the disk DTO with model, free, and capacity bytes plus path and timestamp. The sidecar measures actual files, excludes partial `_tmp` downloads, deduplicates resolved paths, coalesces concurrent scans, bounds responses at two seconds, and returns the last truthful measurement when a later scan is slow.
- Replaced the Settings storage sentence with an accessible progress element using downloaded model bytes divided by model bytes plus current free bytes. Refresh runs after install/remove, on focus, on visibility return, and every 30 seconds while visible; renderer updates are latest-request-wins.
