## 2. Chronological Steps

### 2.1 Configuration two columns (T001)

**Plan specification**: Components left, Features right. Ollama URL, VS Code, and the rest full width below. Narrow window stacks columns.

**What happened**: `QGridLayout` hosts `config-components-column` and `config-features-column`. `resizeEvent` uses the event width and restacks Features under Components below 560 px.

### 2.2 Review two columns and copy (T002, T004)

**Plan specification**: Facts left (path, components, GPU, disk, Estimated installation time), models right. GPU via `display_vram_gb`. Zero VRAM omits a GB suffix.

**What happened**: Two card labels (`review-facts-column`, `review-models-column`). 16384 MB prints 16 GB VRAM. Empty selection still reads "none selected" on the right. `_summary_text()` concatenates both columns for older tests.

### 2.3 Unsloth lock and refresh (T003)

**Plan specification**: Refresh on `showEvent`. Host-ok is NVIDIA plus `display_vram_gb >= 16`. Incompatible disables and clears the checkbox. No opt-in warning.

**What happened**: Construct with empty GPU stays Incompatible and disabled. Applying NVIDIA 16384 then `showEvent` becomes Compatible and enabled. 8 GB NVIDIA cannot check. Reverses the v2.4.2 opt-in warning.
