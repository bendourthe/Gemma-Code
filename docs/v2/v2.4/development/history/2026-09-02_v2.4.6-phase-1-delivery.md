## 2. Chronological Steps

### 2.1 Fail closed on a stale desktop payload (T001)

**What happened**: The freeze step used to Copy-Item the first matching `Nexus AI Studio_${Version}_x64-setup.exe` and write `manifest.json` in PowerShell. Version equality was necessary and not sufficient: last week's binary still matched 2.4.1.

`nexus_installer.engine.desktop_payload.stage_desktop_payload` now copies, hashes, and writes the manifest. It refuses a missing file, a filename that does not encode the product version (`2.4.1` does not match `2.4.10`), and a bundle whose mtime is older than `desktop/src`, `desktop/sidecar/src`, `desktop/src-tauri/src`, and the pin files. `build-windows.ps1` calls `stage-desktop-payload.py` and exits 1 on that failure. It does not invoke `npm run build:shell` (too long for this gate); the error tells the operator to run it.

A freshly copied stale NSIS whose LastWriteTime is newer than source can still pass the mtime check. That is recorded as WN-1. The field case (old tauri output left in `desktop/src-tauri/target/...`) is the mtime miss the tests pin.

### 2.2 Desktop fingerprint (T002)

**What happened**: After a successful desktop install, the provisioner writes `~/.nexus/desktop-payload.json` (version + sha256) from the embedded manifest. A local `--desktop-bundle` override writes `version: local-override` and does not consult the embedded payload (so the override test still proves the payload is skipped). Settings shows `Desktop payload {version} ({12-char hash})` or `Desktop payload unknown`. Sidecar method `runtime.desktopPayload` reads the file; a missing file is null, never a guessed 2.4.1.

### 2.3 First presentation is maximized (T003)

**What happened**: `present_installer_window` calls `showMaximized`. `main.py` no longer calls `window.show()`. `show_and_raise` still uses `showNormal` for tray reattach.

### 2.4 Testing (T004)

Installer pytest for staging, identity, maximize helper, and packaging script shape. Desktop vitest for Settings fingerprint and sidecar dispatch. `npm rebuild better-sqlite3` was required before Node tests after an earlier Electron ABI rebuild (v2.4.5 WN).
