## 2. Chronological Steps

### 2.1 Stick to bottom (T009)

**Branch**: `feat/v2.4.1-field-reliability` | **PR**: none | **Merged to**: n/a

**Plan specification**: On composer submit, always `scrollTop = scrollHeight`. Incoming tokens follow only while pinned (48px slack). Empty transcript does not throw.

**What happened**: Added `desktop/src/shared/chat/useStickToBottom.ts`. Wired Chat, Agents, Image, and Video overflow panes. Chat and Agents expose `data-testid="transcript-scroll"`. Composer `stickNow()` always pins; `followKey` only applies when pinned.

**Key files changed**: `desktop/src/shared/chat/useStickToBottom.ts`, `desktop/src/modules/chat/ChatPage.tsx`, `desktop/src/modules/coding/CodingPage.tsx`, `desktop/src/modules/image/ImageStudioPage.tsx`, `desktop/src/modules/video/VideoLabPage.tsx`

**Troubleshooting**:
- **Problem**: CodingPage called `stickNow` in `handleSubmit` before the hook ran (TDZ).
- **Root cause**: Hook was declared after `handleSubmit`.
- **Resolution**: Moved `useStickToBottom` to just after `turns` / `busy` state.

**Verification**: Honesty harness: after scroll-up, `stickNow` sets `scrollTop` to mocked `scrollHeight`.

### 2.2 Honest context meter (T010)

**Plan specification**: Visual sessions use a session budget (default at least 8), not catalog `maxImages: 1`. Warning quotes the live percent, not a hardcoded 80. LLM `contextWindow` path unchanged.

**What happened**: `SESSION_VISUAL_CAP_DEFAULT = 8` is the footer denominator whenever a visual budget exists. One image with `maxImages: 1` is 12.5%. Two images are 25%. `ComposerContextRow` reads `This session is at {N}% of context.`

**Key files changed**: `core/chat/sessionContextUsage.ts`, `desktop/src/shared/chat/ComposerContextRow.tsx`

**Verification**: Core unit tests plus honesty and ContextUsageBar tests.

### 2.3 Generic delete copy and multi-select (T011-T012)

**Plan specification**: Question is "Delete the selected chat?" / chats / folder / folders / items with no title interpolation. Second line: "This action cannot be undone." Ctrl/Cmd toggle, Shift range, Escape clears, Delete operates on the set.

**What happened**: Copy lives in `folderTreeDeleteCopy.ts`. Folder warning has no names. Archive instead remains for a single chat. Drag moves the whole selected set when the drag started on a selected row.

**Key files changed**: `desktop/src/modules/chat/folderTreeDeleteCopy.ts`, `desktop/src/modules/chat/FolderTree.tsx`

**Verification**: FolderTree tests (35) plus honesty copy cases.

### 2.4 Concise model titles (T013)

**Plan specification**: Create as "New chat", then 3-6 word model title. Timeout or no resident model keeps `fallbackTitle` (about 6 words), never `sessionTitleFromPrompt`'s 45-character slice. User rename is never overwritten.

**What happened**: Image/Video `ensureSession` creates "New chat", then immediate fallback, then `refineGeneratedTitle` via `chat.generateTitle` after the job is accepted. Agents `coding.session.start` default title is "New chat". Overlay tracks `userRenamed`. Studio adapter stores `userRenamed` in an in-memory Map; `studioAsChatExplorer` no longer hardcodes `userRenamed: true`.

**Key files changed**: `desktop/src/shared/explorer/scheduleFirstPromptTitle.ts`, `desktop/src/shared/explorer/studioAsChatExplorer.ts`, `desktop/src/shared/explorer/codingSessionsAsChatExplorer.ts`, `desktop/sidecar/src/coding/sessionManager.ts`, Image and Video pages

**Verification**: Honesty tests: fallback is shorter than the 45-char slice; refine no-ops when `userRenamed` is true.

### 2.5 Testing and stabilization (T014-T015)
