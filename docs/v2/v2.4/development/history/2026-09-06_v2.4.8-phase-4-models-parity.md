## 2. Chronological Steps

### 2.1 Tab order (T014)

**What happened**: Installer `TYPE_TABS` is Embeddings, Document, Chat, Agentic, Image, Video, Audio. Desktop `CATALOG_TAB_DEFS` had Document last; its comment claimed installer parity, which had been true until the installer moved Document next to Embeddings. The desktop tuple now matches, and `tests/fixtures/v2.4.8-catalog-tab-order.json` is asserted from `catalogTabs.test.ts` and from the new `scripts/installer/tests/test_desktop_parity_fixtures.py`.

### 2.2 Provider colors (T015)

**What happened**: The desktop had no provider color map. `desktop/src/shared/models/providerColors.ts` mirrors installer `PROVIDER_COLORS`, `PROVIDER_FALLBACK`, `BADGE_RECOMMENDED` (`#4682b4`), and `BADGE_DOWNLOADED` (`#a78bfa`), keyed through the existing `FAMILY_TO_PUBLISHER` twin, and adds `providerTint()` as the `color-mix()` equivalent of the installer's `rgba_css()`. `tests/fixtures/v2.4.8-provider-colors.json` is asserted on both sides.

### 2.3 Card grammar (T016)

**What happened**: `ModelCard` in `ModelsSettings.tsx` was redrawn element by element from `typed_catalog.py`:

| Installer | Desktop |
|---|---|
| `rgba(accent, 0.09)` fill, `rgba(accent, 0.30)` border, 8 px radius, 14 / 10 margins | `color-mix` 9 % fill, 30 % border, 8 px radius, `10px 14px` padding |
| Name bold in accent (muted when it does not fit) | same |
| `derive_fact_pills` on the name row, one-color `_pill` | `buildModelPills` on the name row, one-color `Pill` |
| `Required` (accent) / `Recommended` (steelblue) / `Tool calling verified` | same, same test ids |
| Size pill in accent; round `✓` / `!` compatibility badge; round `⤓` downloaded badge | same, tooltips carry the wording |
| Dashed muted border and dim when over budget, incompatibility note under the name row | same |
| Description, `Best for:`, `Use restriction:`, `Why this one:` (recommended only) | same |
| Checkbox | Action row: star, download or delete (unchanged) |

Removed: the `Requirements:` row, the separate compatibility text badge, the two-tone pill label / value split, and the type icon. `MODELS_CARD_PADDING` is now the installer's `10px 14px`. This reverses the v2.4.6 Phase 6 decision to drop `Best for` and `Why this one` from Settings; parity with the installer is the operator's stated requirement and the card comment records the reversal.

### 2.4 Tests (T017, T018)

**What happened**: `test_desktop_parity_fixtures.py` (3 tests) and `providerColors.test.ts` (4 tests) are new. `catalogTabs.test.ts` reads the order fixture. `ModelsSettings.test.tsx` and `settings-models-density.test.tsx` had their grammar assertions rewritten: name-row pill order for LFM, SANA, and Gemma 4 12B; the compatibility badge accessible name; the incompatibility note; steelblue Recommended; provider tint on the row; one-color chips; `Best for` present when the row carries strengths; `Why this one` only for recommended rows. jsdom reports inline colors as `rgb()`, so the expectations use that form.
