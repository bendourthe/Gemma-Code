### 2.7 Full-suite testing (T026)

**What happened**: Green, after diagnosing two environment findings.

**The VSIX build leaves `node_modules` unusable by the Node suite.** The first root-vitest run reported 495 failures across 64 files, all `NODE_MODULE_VERSION 146` vs required `137` on `better_sqlite3.node`. This is not a defect in this cycle's code: `scripts/build-vsix.ps1` deliberately rebuilds the native module for Electron 42.8.1 (ABI 146) so the packaged extension works, and Node 24 needs ABI 137. Building an installer therefore breaks the Node suite until `npm rebuild better-sqlite3`. This retroactively explains the 33 failures seen at the start of the v2.4.4 session, which followed an earlier VSIX build. After rebuilding: 495 failures became 3.

**The remaining 3 are contention-sensitive performance budgets.** A 15-second consolidation budget, a p50/p99 retrieval latency budget, and one golden-runner case. Re-run in isolation on the same tree, all 18 tests in those three files pass; they failed only while heavy builds ran concurrently. Not treated as product defects, and not silently omitted from the evidence either.

Final: root vitest 5734 passed, desktop vitest 1963 passed, `tests/python` 292 passed, installer suite 100% with no fatal exception, root lint / `tsc -b` / installer ruff all clean.
