## 2. Chronological Steps

### 2.1 Equal gutters (T001)

**What happened**: The pending pill's left offset came from three independent declarations that summed: `PendingMessage` set `paddingInline: var(--space-2)` and then `paddingLeft: calc(var(--space-2) + 12px)` on top of it, and `AgentStateOrb` added another `marginLeft: 12`. Meanwhile the message list itself had `padding: 0`, so completed assistant bubbles sat flush at 0. That difference is the drift in screenshot 1, and it is why raising the inset in v2.4.3 made it worse rather than better.

The fix inverts ownership. `MessageList` now exports `TRANSCRIPT_GUTTER_PX` (12) and applies it as `paddingInline` on the `<ul>`. Because it is inline padding rather than a one-sided margin, the same declaration produces the assistant bubble's left margin and the user bubble's right margin, which is the symmetry the definition of done asks for. `PendingMessage` and the in-bubble pending block now add no inline padding at all.

### 2.2 Single uncropped glow (T002)

**What happened**: `PENDING_PILL_INSET_PX` was deleted rather than set to 0; a constant that must always be zero is a trap for the next reader. `AgentStateOrb` no longer sets `marginLeft`. The glow is a `box-shadow` on the pill chrome layer, so it paints outside the pill's border box; the list gutter is the space it now lands in. `overflow: visible` was added to the list and to each row so nothing between the pill and the scroll container clips it. The scroll container is `overflowY: auto`, which computes `overflow-x` to `auto` as well, so the gutter (not `overflow: visible` alone) is what actually keeps the halo on screen.

`pendingPillMinWidthExpr` is untouched, so the pill is still sized by `longestPendingCaption()` (`Searching...`) and does not resize as the caption rotates.

### 2.3 Testing and stabilization (T003)

**What happened**: Five new cases in `desktop/tests/AgentStateOrb.test.tsx` pin the gutter contract: the list carries one `paddingInline` on both edges, list/row/pending are all overflow-visible, the pending row and orb add no second inset, the pill keeps its caption-driven min-width, and studio hero pending stays centered without inheriting the chat pill chrome.

Three existing tests had pinned the old 12px inset as the intended behavior and were rewritten to the new contract rather than deleted: `pendingCaptionRotator.test.tsx`, `sidebar-history-host.test.tsx`, and `transcript-v2.4.1-corrections.test.tsx`.

One unrelated discovery: 33 sidecar tests were failing on this host before any edit, all from `better-sqlite3` compiled against NODE_MODULE_VERSION 146 while Node 24.13.0 requires 137. `npm rebuild better-sqlite3` cleared all 33. This touched `node_modules` only; no tracked file changed.
