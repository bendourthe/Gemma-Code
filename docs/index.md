## Module purposes

### `agents`

Sub-agent orchestration: SubAgentManager spawns scoped verification, research, and planning sub-agents; SpecialistLoader resolves prompts via the workspace -> bundled -> hardcoded priority chain (ADR-0004).

### `chat`

Conversation, prompt assembly, streaming, and the six-stage compaction pipeline (ADR-0003). PromptBuilder owns budget allocation; ContextCompactor owns the strategy chain.

### `commands`

Slash command router for in-extension commands like /memory, /verify, /research, /commit, /review-pr.

### `config`

Settings reader (vscode.workspace.getConfiguration) and prompt-budget allocator. Single source of truth for percentage-based budget splits across system prompt, memory, skills, conversation, and reserve.

### `evaluation`

Golden-task suite plus the YAML cross-check generated by scripts/generate-golden-tasks.mjs. Smoke set runs in-process; harness corpus runs out-of-process.

### `guardrails`

Pre-execution safety layer: ActionClassifier, GitSafetyNet (checkpoints + protected-branch refusal), LoopDetector, BudgetEnforcer, PermissionTiers (ADR-0005).

### `llm`

Vendor-neutral LLM port at types.ts; the Ollama HTTP adapter at OllamaClient/OllamaHttp. The only module allowed to import the concrete Ollama clients (modulo grandfathered baselines).

### `mcp`

Model Context Protocol client (consume external servers) and server (expose Gemma's tools to other clients). Lifecycle managed by McpManager.

### `observability`

Tracer + TraceStore for structured spans; MetricsCollector for counters; OtlpExporter for optional OTLP HTTP fan-out (off by default for offline-first).

### `orchestration`

Orchestrator + PlannerAgent + DAGExecutor + ReflexionEngine for multi-step plan execution. Composes sub-agents from src/agents/.

### `panels`

VS Code webview panels and message protocol. Communication with the runtime goes through panels/messages.ts; direct storage imports are forbidden.

### `runtime`

GemmaRuntime composition root. Wires Tracer, settings, and the dependency graph that the panel and command layers consume.

### `skills`

User-defined skill loader. Reads SKILL.md files from ~/.gemma-code/skills/ and contributes them as system-prompt augmentations.

### `storage`

Four-layer memory (Working, Episodic, Semantic, Graph) plus ChatHistoryStore, ToolOutputCache, and the consolidator. UnifiedMemoryRetriever is the public retrieval API (ADR-0002).

### `tools`

Tool registry, agent loop, output redirector, and the handlers under tools/handlers/. Routes every call through ConfirmationGate and PermissionTiers.

### `utils`

Logger, error formatting (formatForUser/formatForLog), Markdown renderer (DOMPurify-sanitized), and small shared helpers.
