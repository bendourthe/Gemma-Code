# v1.9.0 Phase 3 -- Installer visual overhaul + naming + NexusAI path

**Date**: 2026-07-04
**Plan**: [../../plans/installer-and-app-experience-overhaul.md](../../plans/installer-and-app-experience-overhaul.md) (Phase 3)
**Scope**: restyle the PyQt wizard to the north-star guide's look and finish the installer rebrand -- a frameless dark title bar, the Phase 2 constellation mounted over a radial-glow body, the floating-glow logo in the header + welcome hero, a glowing step indicator, the "Nexus AI Studio" naming, and the `NexusAI` install path.

## What landed

The v1.8.0 wizard was a plain `QMainWindow` with a native OS title bar (`"Nexus -- Setup"`), a black-box `assets/icon.png` header mark, a `GemmaCode` default install path, and no constellation / glow anywhere. Phase 2 built the shared brand primitives (transparent+rounded icons, glow tokens, `ConstellationBackground`, `FloatingLogo`) but left them unmounted by design. Phase 3 consumes them in the installer so it finally reads as the product it installs.

### Tasks

- **T301 -- frameless title bar** ([widgets/title_bar.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/widgets/title_bar.py) + [window.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/window.py)): the window switches to `Qt.FramelessWindowHint | Qt.Window` and grows a custom `TitleBar` band -- a transparent glowing brand mark (`GraphicsDropShadowEffect`, static; chrome does not bob) + "Nexus AI Studio" wordmark + minimize / maximize-restore / close buttons. Drag-move uses the native `windowHandle().startSystemMove()` where available with a manual delta-move fallback (`_begin_drag` / `_drag_target`, unit-tested pure math); double-click toggles maximize; two bottom-corner `QSizeGrip`s handle resize. `changeEvent` swaps the maximize glyph to a restore glyph on `WindowStateChange`. A `NEXUS_NATIVE_TITLEBAR` env var (or `InstallerWindow(frameless=False)`) restores native decorations as the documented fallback (plan Risks table); the grips + title bar are omitted in that mode. New attributes are pre-initialized before the first `resize()` so the overridden `resizeEvent`/`changeEvent` never touch not-yet-created widgets.
- **T302 -- constellation body** ([widgets/background.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/widgets/background.py)): a `BackgroundWidget` paints the two `RADIAL_GLOW_POOLS` cyan/blue pools fading into `BG_DEEP` (`QRadialGradient` over a `BG_WINDOW`->`BG_DEEP` `QLinearGradient`) and hosts the Phase 2 `ConstellationBackground` at `0.55` opacity (`QGraphicsOpacityEffect`) inside a zero-margin layout (so it always fills the host as the window resizes). It is mounted as a lowered child of the central widget; the content path (scroll area + `#scrollViewport` + `#contentWrapper` + its direct-child pages) is made transparent in [theme.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/theme.py) so the animation shows through the content band while the chrome bands (title bar, header, footer) and the step-indicator band stay opaque for readability. **`IAE.P2.A` partially closed**: `resolve_reduced_motion()` wires the `NEXUS_REDUCED_MOTION` env var **and** the real Windows `SystemParametersInfo(SPI_GETCLIENTAREAANIMATION)` query (extracted to a monkeypatch-friendly `_windows_animations_disabled()`); the background + header/welcome logos feed it into `reduced_motion=`.
- **T303 -- header + welcome + step indicator** ([widgets/header.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/widgets/header.py), [pages/welcome.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/pages/welcome.py), [widgets/step_indicator.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/widgets/step_indicator.py)): the header's black-box `QLabel(icon.png)` becomes a small (30px) `FloatingLogo` (glow + gentle bob); the welcome page's 56px black-box desktop icon becomes a 64px `FloatingLogo` hero (the now-unused `_find_desktop_icon` resolver + `QPixmap`/`Path` imports were removed to keep lint clean). The step indicator gains a soft cyan halo (`_draw_glow`, three translucent expanding ellipses) behind completed dots and a highlighted current dot (glow + `0.18`-alpha accent fill). Header + welcome titles now read "Nexus AI Studio" / "Welcome to Nexus AI Studio".
- **T304 -- rebrand** ([main.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/main.py), [window.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/window.py)): window/taskbar title `"Nexus -- Setup"` -> `"Nexus AI Studio"`; `QApplication` `setApplicationName` / new `setApplicationDisplayName` -> "Nexus AI Studio"; argparse description "Nexus Installer" -> "Nexus AI Studio Installer"; `--version` `gemma-code-installer` -> `nexus-ai-studio-installer`; module docstring de-Gemma'd. A grep confirms zero user-visible "Gemma" / "Nexus -- Setup" / "Nexus Installer" strings remain in the wizard UI modules (the remaining `gemma-code` references are intentional backward-compat: the `extension_installer` legacy VSIX id + the `storage_migration` `~/.gemma-code` source, plus the unwired legacy pages removed in Phase 4 and non-user-visible engine/package docstrings).
- **T305 -- install path** ([installer_state.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/installer_state.py), [pages/install_path.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/pages/install_path.py)): `_default_install_path()` -> `C:\Program Files\NexusAI` / `/Applications/NexusAI` / `/usr/local/share/nexus-ai`; the storage callout's "Gemma model" line -> "Nexus models".
- **T306 -- optional riders** (partial): the exe icon references in `main.py` already point at the Phase 2 transparent+rounded `assets/icon.{ico,png}` (no change needed). TTF font bundling (Inter / JetBrains Mono) is **deferred** as `IAE.P3.C` (optional; the wizard uses the platform font stack).
- **T307 -- tests**: new [test_title_bar.py](../../../../../../scripts/installer/pyqt/tests/test_title_bar.py) (construction, controls, signal wiring, drag math, double-click, non-left delegation, glyph swap, move), new [test_background.py](../../../../../../scripts/installer/pyqt/tests/test_background.py) (reduced-motion resolver env/Windows/non-Windows, constellation host, resize, render), plus additions to `test_window.py` (frameless flag, title bar, background mount, grips, native fallback, close wiring, maximize toggle), `test_pages_qt.py` (welcome title + `FloatingLogo` hero; install-path NexusAI default + "Nexus models" callout), `test_installer_state.py` (NexusAI per-OS default), and `test_widgets.py` (step-indicator glow restyle renders at every step).

## Verification (DoD proof)

- **Composition smoke** (offscreen Qt, dev box): built the full wizard exactly as `main.py` does (all pages), showed it, switched through pages, grabbed frames -- frameless `Nexus AI Studio` window, title bar wordmark "Nexus AI Studio", constellation running, default path `C:\Program Files\NexusAI`, no crashes.
- **Rebrand**: `--version` -> `nexus-ai-studio-installer 1.1.0`; `--help` description -> `Nexus AI Studio Installer`; grep of the UI modules -> zero Gemma/old-name strings.
- **Installer suite**: `pytest tests/` (offscreen Qt) -> **671 passed, 2 skipped, 0 failed** (+39). New/changed widget coverage: `title_bar` 91% / `background` 97% / `header` 100% / `step_indicator` 99% / `window` 83% lines.
- **Lint**: `ruff check` + `ruff format --check` clean on all changed/new files. (Pre-existing repo debt left untouched per scope: the installer source's UTF-8 BOMs on older files, and one >88-char E501 on the untouched VS Code line in `install_path.py`. New files are BOM-less, matching the Phase 2 convention.)
- **No TS / desktop change**: Phase 3 is installer-only (the desktop-app parity pass is Phase 5), so no Vitest / `tsc` run is in scope.
