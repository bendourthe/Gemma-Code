# v1.9.0 Phase 2 -- Shared brand foundation (icons + tokens + constellation primitive)

**Date**: 2026-07-04
**Plan**: [../../plans/installer-and-app-experience-overhaul.md](../../plans/installer-and-app-experience-overhaul.md) (Phase 2)
**Scope**: brand-asset + design-system foundation -- fix the black-box icons, add the guide's glow token layer to both stacks, and build the reusable constellation + floating-glow-logo primitives the installer (Phase 3) and the app (Phase 5) will consume, so the two read as one product.

## What landed

The shipped v1.8.0 icon set was opaque black (every `assets/` and `desktop/src-tauri/icons/` PNG/ICO/ICNS had corner alpha 255 and a 1.00 opaque ratio), so the logo read as a black box in the header, taskbar, and dock -- even though the designer source (`assets/nexus-ai-primary_no-background.png`) and `desktop/src-tauri/icons/window-icon.png` were already transparent. The desktop app and installer shared the base dark palette but had no glow layer, no constellation background, and no floating-logo treatment, so neither matched the north-star guide (`guides/interactive-guide/nexus-ai-guide.html`).

Phase 2 fixes the icons at the generator, ports the guide's glow tokens into both palettes, and ships the animated-background + floating-logo primitives in both stacks (built and unit-tested in isolation; mounted by Phase 3/5).

### Tasks

- **T201 -- icons** ([scripts/desktop/generate-icons.py](../../../../../../scripts/desktop/generate-icons.py)): the generator already resized straight from the transparent source (no opaque composite in code) -- the committed black icons were simply stale, from an older opaque-source run. Re-running now would already restore alpha; on top of that, added a `_superellipse_alpha_mask(size)` helper (per-row span fill of `|x/a|^n + |y/b|^n <= 1` with n=4, supersampled 4x + LANCZOS-downscaled for a smooth edge, cached by size) and `_apply_rounded_corners()` (multiplies the mask into the existing alpha, so it only ever *removes* corner opacity, never paints a fill). `render_square(..., rounded=True)` now rounds every emitted frame. Re-ran the generator: `assets/icon.{png,ico,svg}`, `assets/sidebar-icon.svg`, and the full `desktop/src-tauri/icons/` set (PNG sizes, `.ico`, `.icns`, Store tiles) are now transparent + squircle-rounded. Because the source mark is a near-full-bleed emblem (content fills 95%x99% of the frame), the squircle is genuinely visible, not a no-op.
- **T202 -- tokens** ([desktop/src/styles/tokens.css](../../../../../../desktop/src/styles/tokens.css) + installer [constants.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/constants.py)): added the guide's glow layer to both palettes, additively (base tokens untouched) -- `--bg-deep` / `BG_DEEP` (#010608), constellation colors `--glow-cyan`/`--glow-cyan-node` + `CONSTELLATION_LINK`/`CONSTELLATION_NODE`, glow drop-shadows `--glow-sm/md/lg` + `GLOW_RGBA`/`GLOW_BLUR_*`, the signature gradient `--grad-signature`(+`-soft`) + `SIGNATURE_GRADIENT_STOPS`, and the radial-glow background `--bg-radial-glow` + `RADIAL_GLOW_POOLS`. Recorded in [design-tokens.md](../../design-tokens.md).
- **T203 -- primitives**: the guide's canvas routine ported to a pure, canvas-free engine ([desktop/src/components/constellation.ts](../../../../../../desktop/src/components/constellation.ts): `computeNodeCount` = max(18, min(46, w/34)), `clampDpr` <= 2, `createNodes`/`stepNodes`/`drawFrame`, `prefersReducedMotion`), wired into a React canvas component ([ConstellationBackground.tsx](../../../../../../desktop/src/components/ConstellationBackground.tsx)) that honors `prefers-reduced-motion` (single static frame), pauses on `visibilitychange`, and is `pointer-events:none` + `aria-hidden`. The PyQt twin ([constellation.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/widgets/constellation.py)) is a transparent `QWidget` (QTimer ~60fps + QPainter, node-count cap 46, pauses on `hideEvent`, resumes on `showEvent`, reduced motion via `NEXUS_REDUCED_MOTION`). The floating-glow logo primitive: React [FloatingLogo.tsx](../../../../../../desktop/src/components/FloatingLogo.tsx) (drop-shadow `--glow-*` + the new `@keyframes nexus-float` in [globals.css](../../../../../../desktop/src/styles/globals.css), reduced-motion disabled) and PyQt [float_logo.py](../../../../../../scripts/installer/pyqt/src/nexus_installer/widgets/float_logo.py) (`QGraphicsDropShadowEffect` blur 24 / `rgba(56,189,248,.5)` + a `QPropertyAnimation` bobbing +/-9px over 7s InOutSine on a `floatOffset` pyqtProperty), both fed the transparent mark. Both new PyQt widgets exported from `widgets/__init__.py`.
- **T204 -- tests**: installer -- `test_icon_generation.py` (superellipse mask shape, `render_square` rounding clears corners + preserves center + is no longer a solid block + never composites onto a fill, and the committed icons have transparent corners + non-opaque backgrounds), `test_constellation.py` (node-count bounds, reduced-motion never runs, start/stop, resume keeps count, hide/show pause/resume, edge bounce, render), `test_float_logo.py` (default/missing pixmap, start/stop animation, reduced-motion, `floatOffset` moves the mark, show/hide), `test_brand_tokens.py` (glow-layer constant presence). Desktop -- `constellation.test.ts` (engine), `ConstellationBackground.test.tsx` (mocked 2d ctx + rAF: loop, reduced-motion static, hidden-pause, resize, no-context no-op, unmount cleanup), `FloatingLogo.test.tsx`, `brandTokens.test.ts` (CSS token + keyframes presence via fs). Added `Pillow>=10.0` to the installer dev deps so the icon assertions run in CI (they `importorskip` otherwise).
