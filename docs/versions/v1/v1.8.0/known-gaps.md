# v1.8.0 -- Known Gaps, Deferrals, and Carryovers

**Status**: IN PROGRESS -- Phases 1-3 of 6 closed (Phases 1-2 on 2026-07-02, Phase 3 on 2026-07-03). v1.8.0 is the "one-shot end-user installer" cycle ([plans/one-shot-installer.md](plans/one-shot-installer.md)): download one file, get dependencies + VS Code extension + models + the Nexus desktop app installed and launchable. Phase 1 makes the release pipeline emit versioned, checksummed desktop bundles (the fetch-from-release prerequisite): a `desktop-bundle` 3-OS job set in `release.yml` (T101), a single `SHA256SUMS.txt` verification asset (T102), the `GemmaCodeSetup.*` -> `NexusSetup.*` artifact rename (T103), and a local Windows `tauri build` proof with the NSIS bundle stashed as the Phase 2 fixture (T104). Phase 2 makes the installer install Nexus: a fail-closed `desktop_provisioner` (T201), engine step 5 + component threading (T202), a first-run health check + "Launch Nexus" finish hook (T203), and a 39-test suite incl. a real fixture-install integration leg (T204). Phase 3 makes image/video model selection real (gap G2): per-model `weights` manifests in catalog.json + a documented destination-layout contract + a pin-rotation script (T301), a resumable SHA-256-verifying `hf_weights_puller` (T302), protocol routing with weighted mixed progress + per-model failure isolation (T303), and 62 new tests incl. an env-gated GPU-box smoke (T304). This file is appended phase-by-phase; items move to `## 2. Resolved` when closed.

**Audience**: v1.8.0 phase authors, code reviewer, future-cycle planners
**Last updated**: 2026-07-03 (Phase 3 close)
**Sibling reviews**: [../v1.7.0/known-gaps.md](../v1.7.0/known-gaps.md) (the prior cycle's gap log; `RT.P7.A`/`RT.P7.B` interact with Phase 2 below) and [plans/one-shot-installer.md](plans/one-shot-installer.md) (the active plan).

**Cycle-wide constraint**: GitHub Actions minutes are frozen ($0 budget) until 2026-08-01 (2026-07-02 CI incident). Every CI-leg claim below is therefore `future` tier until the post-freeze rehearsal (Phase 6, T603); local proofs are the only `supported` evidence this cycle.
