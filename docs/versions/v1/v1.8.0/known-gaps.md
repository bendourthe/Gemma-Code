Phase 6 closes gap G5's buildable half: the Windows pipeline is real end-to-end locally -- PyInstaller wizard + NSIS outer -> `NexusSetup.exe` + silent-install smoke (T601, also closing the `OSI004.P4.C` registry-packaging P1), the mac/linux workflows aligned to the canonical spec-driven build scripts, and the end-user download/install page (T605); the whole-plan DoD (3-platform rehearsal from published pre-release artifacts) rides the T602-T604 entries below.
